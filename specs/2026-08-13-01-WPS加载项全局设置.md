## 1. 要解决什么

1. 「内容重复」等校对选项不该钉在校对条上，应进 **校对设置**。  
2. 加载项缺全局设置入口；账号钮旁需要 **设置图标**，能管整个助手偏好。  
3. 对齐原编辑器「通用 / 撰写 / 精修 / 校对」分类，避免再造一套交互。

**原则：** 用户设行为偏好；**不**选手动换模型/厂商（路由在中转）。

---

## 2. 原项目怎么设计（对照）

| 项 | 浏览器编辑器 |
|----|----------------|
| 入口 | 顶栏「设置」菜单 →「打开设置…」或分栏直达 |
| 形态 | 模态框；左导航 + 右内容 |
| 分类 | **通用 · 撰写 · 精修 · 校对** |
| 校对子页 | 偏好 / 场景 / 词库 / 数据 |
| 引擎 | 按场景勾选；与校对条 chips 同步 |
| 落盘 | 工程 `.gongwen/config.json`（工程级） |

校对默认引擎示例（政务）：快速档开、`style`/`logic`/`dataverify` 默认关。  
商业化定调：这套大对话框继续用；登录/分类/额度往里加。

## 3. 加载项定案

### 3.1 入口

- 位置：顶栏右侧 `aiHeadActions`，**设置图标在账号钮左侧**  
  形如：`⚙` | `测试`（或登录名）
- 点击：打开设置模态框；可带初始页（如从校对 Tab 深链到「校对」）
- 账号钮职责不变（登录/额度）；设置不管登录表单主路径（通用页可放「账号状态」只读 +「打开账号」弱链）

### 3.2 形态

```
┌─────────────────────────────────────┐
│ 设置                            × │
├────────┬────────────────────────────┤
│ 通用   │  （当前分类内容）           │
│ 撰写   │                            │
│ 精修   │                            │
│ 校对   │                            │
└────────┴────────────────────────────┘
```

窄侧栏内：左栏约 72–88px，右栏可滚动；风格贴近现有 `ai-aside`，不做第二套皮肤。

### 3.3 信息架构（一期 / 二期）

| 分类 | 一期（必做） | 二期（对齐编辑器） |
|------|--------------|-------------------|
| **通用** | 账号状态只读 | 工程改绑（只在左侧工程栏）；定时保存等 |
| **撰写** | 占位说明 + 已有可搬项（若有文种码）；不强行造参照路径 UI | 文种、参照稿、对照旧稿、默认授权改稿 |
| **精修** | 默认方案套数（2–6）、默认预览（diff/新稿） | 必须选区等细项 |
| **校对** | **偏好**（灵敏度、默认范围）+ **引擎勾选**（含 `duplicate` 内容重复） | 场景套装、词库、事实表、校对条 chips |

### 3.4 校对设置（一期焦点）

**偏好**

| 项 | 默认 | 作用 |
|----|------|------|
| 灵敏度 | `normal` | 传 `sensitivity` |
| 默认范围 | `full` | 打开校对 Tab / 首次进入时单选默认（用户当次可改） |

**引擎勾选**（与 `proofread.py` `ENGINE_META` 对齐）

| 组 | 引擎 | 默认 |
|----|------|------|
| 快速 | punctuation / format / dictionary / typo / grammar / sensitive | 开 |
| 深度 | style / logic / dataverify | 关 |
| 深度 | **duplicate（内容重复）** | **开** |

- 开始校对：按设置拼 `engines[]` 调 `/api/proofread`。  
- **校对条去掉「内容重复」勾选**；条上只留 选区|全文 + 开始/清空。  
- 文案提示：「更多检查项请到设置 → 校对」。

与 `2026-08-13-03-WPS校对内容重复.md` 关系：能力定义仍以该文为准；**开关归属以本文为准**（设置，非校对条）。

## 4. 落盘

| 层 | 一期 | 说明 |
|----|------|------|
| 本机 | `PluginStorage` + `localStorage` 兜底 | 扩展 `userPrefs` 或新建 `settingsStore.js`；键如 `gongwen.settings.v1` |
| 工程 | 可选 | 已绑定工程根时，可同步写 `.gongwen/config.json` 的 `ai` 段（对标编辑器）；**未绑定则只写本机** |
| 云 | 不上云 | 偏好不进账号同步（二期若要「换机」再议） |

结构草案（可裁）：

```json
{
  "general": { "projectRootHint": true },
  "write": {},
  "suite": { "count": 3, "optView": "diff" },
  "proof": {
    "sensitivity": "normal",
    "defaultScope": "full",
    "engines": {
      "punctuation": true,
      "format": true,
      "dictionary": true,
      "typo": true,
      "grammar": true,
      "sensitive": true,
      "style": false,
      "logic": false,
      "dataverify": false,
      "duplicate": true
    }
  }
}
```

非法/未知引擎 id 忽略；缺省键用上表默认值合并。

## 5. 交互细则

1. 改勾选即写盘（或「关闭时保存」二选一；**推荐即时写盘**，少丢改）。  
2. 设置打开时从磁盘灌入；与内存态一致。  
3. 校对进行中改引擎：不影响当次请求，下次「开始校对」生效。  
4. 深链：`openSettings('proof')`；校对空态可链到设置。  
5. 不暴露模型名、不暴露厂商路由。
