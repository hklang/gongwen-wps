## 0. 设计原则（先于页面）

| 原则 | 含义 |
|------|------|
| **无感优先** | 绝大多数人点「开始校对 / 出方案 / 发送」就能用；**从不进设置也能写完一篇** |
| **设置只收「会反复用的个性」** | 单位词、数据核验对照表、校对口味；不当次意图（层级、选区、多份） |
| **情境里点，不进选项** | 工程根、参照稿、引用 → 工程栏；当次范围 → 校对条/底栏 |
| **少而深，不照搬四栏全集** | 原编辑器场景/词库/数据能力保留；常用在「校对」一次配完，精修进高级 |
| **壳要大气** | 设置用 **独立 `ShowDialog` 窗**，不在窄助手里盖假模态 |

一句话：**默认像会写公文的同事；设置像「改我单位的习惯」，不是「调参面板」。**

## 1. 功能盘点：什么要设、什么不要设

按现网三 Tab + 工程栏，把能力分成三类。

### 1.1 无感默认（用户不设 · 系统定好）

| 能力 | 默认行为 |
|------|----------|
| 模型档 | 交流 flash / 终稿与精修 pro / 校对 proof；**界面不选手动模型** |
| 精修套数 | 默认 3；用户可在高级改 |
| 精修预览 | 默认 diff |
| 精修须钉住 | 默认开 |
| 校对场景 | 默认 **政务公文**（加载项主场） |
| 校对灵敏度 | 默认 **标准 normal** |
| 内容重复 | 政务场景 **默认开**；其它场景默认关 |
| 数据核验 | 无对照条目时 **自动不跑**（不打扰） |
| 素材精读 | 模型要啥给啥 / 精修自动读；不设「读几篇」 |
| 交稿闸 / Critic | 宿主策略自动；不设开关墙 |
| 窗口几何 | 跟手记忆；不进设置页 |

深度引擎（style/logic）：政务默认 **关**（少误报、更快）；需要时在「校对 · 本场景检查项」打开。

### 1.2 情境操作（主路径点 · 不进设置）

| 能力 | 放哪 |
|------|------|
| 工程改绑、看素材/模板 | **左侧工程栏** |
| 设为/清除风格参照 | **工程文件右键**（条上可显示当前参照） |
| 引用素材 | 工程右键 / 引用条 |
| 钉住选区、同级标题 | 底栏 |
| 一级/二级/正文、出结论/多份 | **撰写底栏当次意图** |
| 充填/润色等 | 精修底栏预设 |
| 校对选区 \| 全文 | **校对条当次** |
| 登录 / 额度 | **账号钮** |

### 1.3 真正要个性化（才进设置）

只保留「记一次、长期管用」的：

| 个性 | 为什么要设 | 频次预期 |
|------|------------|----------|
| **校对场景** | 政务 / 新闻 / 个人，口味不同 | 很少改；设一次 |
| **灵敏度** | 有人嫌吵、有人怕漏 | 偶发 |
| **我的词库**（白名单 + 易错必纠） | 单位专名、领导称谓、常错词——商业化「越用越像本单位」 | **核心个性化** |
| **数据核验对照表**（可选） | 固定营收/人数等，给 dataverify | 少数单位；设置左栏维护 |
| **精修默认套数 / 预览** | 个人习惯 | 很少 |
| 账号入口 | 状态只读 + 打开账号 | — |

**明确不进设置（或长期不做）：**

- 工程当前文件夹  
- 手动选 DeepSeek/GPT  
- 当次「出几份」「写几级」（底栏已有）  
- 授权改稿默认（主路径已弱化；有需要再 P2）  
- 定时保存/存版本（稿在 WPS）  
- 把十个引擎当一级首页

## 2. 对标

| 对标 | 学什么 |
|------|--------|
| **Word 选项** | 独立大对话框；确定/取消；不在选项里改当前文件夹 |

| **iPhone 设置** | 常用极少项在外；专家项进「高级」 |
| **原编辑器** | **能力**（场景引擎、词库、数据核验）要对齐；**版式**不照搬四子页全摊开 |

## 3. 壳：独立设置窗

与助手分离，避免窄窗裁切：

- `ShowDialog(Ex)` 打开 `ui/settings.html`，约 **920×720**  
- 标题：`公文助手 · 设置`  
- 底栏：**取消**（丢 draft）· **确定**（写盘）  
- 助手 ⚙ / 校对「设置」只负责唤起；**废除助手内假模态大设置**  
- 数据：`gongwen.settings.v2` + 有工程根时可选同步 `.gongwen/config.json`

## 4. 信息架构（简单 · 递进）

左栏 **四项**：

```
┌─ 设置 ─────────────────────────────┐
│ 通用    │  账号说明 · 能力说明         │
│ 校对    │  场景 + 本场景检查项勾选    │
│ 我的词库 │  白名单 / 易错必纠         │
│ 数据核验 │  本机对照数字表（启用在校对勾） │
│ 高级    │  精修默认                   │
│              取消        确定         │
└─────────────────────────────────────┘
```

### 4.0 通用

- 账号状态说明（登录仍走助手右上角账号钮；设置窗不嵌登录表）  
- 智能能力说明（不选手动模型）  
- **不设**工程改绑（工程栏）  

### 4.1 校对（人人看得懂）

1. **我在写哪类稿**（三选一卡片，默认「政务公文」）  
   - 政务公文 / 新闻资讯 / 个人写作  
   - 卡片只写口味说明；**下方勾选本场景检查项**（写入 `sceneEngineMap[当前场景]`）  
   - 可「恢复本场景默认」；换场景不丢各自定制  
2. **查得严不严**（灵敏度三档，默认标准）  
3. 默认范围：全文 / 选区（当次仍可在校对条改）

校对条仍只留：选区|全文 · 开始 · 清空 · 设置。

### 4.2 我的词库（个性化主场）

主录入已改：正文划选 → 校对条「收入」，见 `2026-08-15-01`。本页只看/删。

- **别再报这些**（白名单）· **这种错必须改**（易错对）· 数字表  
- **「我的」在云端按账号隔离**（同「我的模板」）；行业预置另仓。正文不上云。  
- 空态：还没有？校对条划选收入即可。

### 4.3 高级（默认不当首页 · 能力仍在）

| 块 | 内容 |
|----|------|
| 精修习惯 | 默认套数 2–6、预览 diff/新稿、必须钉住 |
| （检查项） | **已迁到「校对」页**，按场景勾选；高级不再重复 |

「数据核验」左栏只维护对照表；是否跑该引擎统一在校对检查项勾选；风格参照主设仍在工程右键（P2 再进设置）。

撰写「文种 / 参照路径浏览」：**P2**；现阶段参照走工程栏。

## 5. 场景默认引擎（无感配方）

| 场景 | 默认打开 | 默认关闭 |
|------|----------|----------|
| 政务公文 | 标点/格式/词库/错别字/语法/政治规范 + **内容重复** | style、logic、dataverify |
| 新闻资讯 | dictionary, typo, punctuation, sensitive | duplicate |
| 个人写作 | dictionary, typo, punctuation | duplicate、sensitive 可按需 |

用户改检查项 → 只写回当前场景；换场景不丢各自定制。

## 6. 数据模型（能力层完整，UI 变薄）

```json
{
  "version": 2,
  "suite": { "count": 3, "optView": "diff", "requireSelection": true },
  "proof": {
    "sensitivity": "normal",
    "defaultScope": "full",
    "scene": "政务公文",
    "sceneEngineMap": {
      "政务公文": ["punctuation", "format", "dictionary", "typo", "grammar", "sensitive", "duplicate"],
      "新闻资讯": ["dictionary", "typo", "punctuation", "sensitive"],
      "个人写作": ["dictionary", "typo", "punctuation"]
    },
    "whitelist": [],
    "mustfix": [],
    "factGroups": [
      { "id": "default", "name": "默认", "enabled": true, "items": [] }
    ],
    "factGroupId": "default"
  }
}
```

- 运行时引擎由 `sceneEngineMap[scene]` 派生，不另存脱节布尔表。  
- v1 扁平 `engines` 迁移进当前场景。  
- `runProof` 传：`engines, sensitivity, whitelist, mustfix, facts`。
