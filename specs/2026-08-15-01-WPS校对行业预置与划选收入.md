## 一句话

点「开始校对」就能用。行业词我们写好。用户自己的词和数，划选一键进词典 / 必改 / 数据，跟账号走。

## 对标

| 产品 | 学什么 | 不学 |
|------|--------|------|
| **Word 拼写** | 选区上「添加到词典 / 自动更正」；忽略本次 ≠ 加入词典 | 自定义词典管理器当主录入 |
| **Grammarly** | 卡片 Ignore once / Always | 大卡挡全文 |

不发明「黑名单」产品名（公文里像人员名单）。三仓仍是：词典（白名单）· 必改（错→对）· 数据（整段口径 + 收录日期）。  
数据对标 **Word「添加到词典」**：划选即存、不拆结构。不学 Excel 抽字段。

## 已定

| 项 | 定法 |
|--|--|
| 主路径 | 校对条：选区\|全文 → 开始校对。设置不是前置 |
| 行业预置 | 政务通用易错随产品带上，**默认开**；设置里可关整包。另仓，不与「我的」云表合并 |
| 收入入口 | 校对条**三个按钮**：词典 · 必改 · 数据。对**当前正文选区**。去掉「收入」下拉 |
| 收入三种 | 词典=别再报（白名单）；必改=错→对；数据=整段原文 + 收录日期，一点即收 |
| 必改无箭头 | 划选里没有「错→对」时：优先用**当前高亮那张卡**的 suggestion；再没有才提示先划「错→对」或先点一条结果。禁止 `window.prompt` |
| 数据 | 不拆 label/value。存选区原文和当天日期。无收录时核验不跑。对不上则报「与×年×月×日收录的数据不一致」 |
| 设置数据核验 | 只展示带日期的原文卡片，可删。禁止在校对条下弹出抽出/勾选面板 |
| 结果条 | 见 `2026-08-16-01`：忽略=本次；永久不报=词典；必须改=必改 |
| 设置 | 「我的」只看/删云端。行业包只开关整包，不当录入台 |
| **用户独立 · 云端** | 「我的」词/数是账号资产。行业预置是产品包。正文/素材不上云 |
| **库形态** | `control.sqlite` 按 `user_id` 隔离。API `WHERE user_id=?` |
| **登录** | 收入「我的」必须已登录。未登录提示先登录，不写本机当主库。关行业包不需登录 |
| **校对读表** | 中转：行业包（若未关）+ 该用户云表，写入提示。客户端不必每次 POST 整表 |
| 判错 | 全部由模型判。词库/必改/数字表只当证据 |
| 换钉 | 再点「开始校对」换新一轮；**清空**才丢掉列表。关 WPS 再开仍在（未点清空） |
