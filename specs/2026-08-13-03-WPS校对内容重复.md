# WPS 校对 · 内容重复（跨段同事项）

日期：2026-08-13  
状态：已定 · 一期实现

## 1. 要解决什么

同一件事/同一段实质内容出现在不同标题下（如「一、（一）」与「三、（一）」各写一遍）。  
目标：**一个内容不该在两个地方出现** → 标出，由人决定删哪边或合并。

**不是**：口径打架、错别字、套话用词重复、与旧稿撞车（后者见商业化「防重复」）。

## 2. 放哪

| 项 | 定法 |
|----|------|
| Tab | **校对**（不进精修） |
| 交互 | 选区/全文 → 开始校对 → 问题列表 → 定位 |
| 开关 | **设置 → 校对 → 引擎「内容重复」**（默认开）；**不**钉在校对条。归属见 `2026-08-13-01-WPS加载项全局设置.md` |
| 动作 | 一期 **只报不改**（无「采纳替换」） |

## 3. 引擎

- id：`duplicate`（tier：deep，kind：llm）
- 勾选时：`DEFAULT_QUICK` + `duplicate`
- 不勾选：仅快速档（与现网一致）
- **全文一次送模型**（禁止按段切分，否则跨「一、」「三、」看不见）
- 宿主不写死任何事项名；模型做语义判重

### 报

- 不同章节/不同同级标题下，同一事项或近义整段复述

### 不报

- 必要呼应一句（「如上所述」）
- 固定套话、文种格式用语
- 同一节内正常展开（非整段克隆）

### 结果字段

沿用校对 `results[]`，并扩展：

| 字段 | 含义 |
|------|------|
| `type` | `duplicate` |
| `original` / `start`/`end` | 一处原文（可定位） |
| `peer` | 另一处原文片段 |
| `path` / `peerPath` | 如 `一/(一)`、`三/(一)` |
| `suggestion` | 固定提示语（非改写稿），如「建议删除本处或与另一处合并」 |
| `reason` | 为何判为重复 |

列表展示两处；「定位」主片段，「另处」再定位 `peer`。
