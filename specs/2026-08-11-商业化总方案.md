# §0 给你看的（尽量一页）

## 我们要做成什么样

**本地写公文的编辑器 + 云端聪明引擎。**  
稿在用户自己电脑里；云端负责：登录、额度、换模型、发写作说明书（手册/模板）。  
不做成网盘，别人才敢用。

**对老手的承诺：** 你本来会写；我们让你少被退稿、少翻旧材料、一段一段改到过关。

## 咱们的真优势：能用上用户自己的旧东西

网页 Chat **摸不到**用户硬盘；咱们可以。不用白不用——从**风格**和**数据**两头吃透本机旧稿/素材。

| 用什么（都在本地） | 帮用户干什么 |
|--------------------|--------------|
| 往年总结、上次汇报、讲话稿 | **学他的口气和结构**（长短句、标题习惯、收尾套话） |
| 同一工程里的旧章节 | **防重复**（和去年撞车的段落标出来） |
| 素材夹里的通知、报表、说明 | **据实写数**（有依据才写；对不上就标） |
| 用户改过的易错词、口径 | **越用越像本单位**（本机词库/记忆，不上云） |

产品上要显眼，不能藏在高级功能里：

1. **写作前**：选「参照稿」（本机旧 md）→ 风格参考，不整篇抄  
2. **写作中**：@素材 / 自动读到的材料要显示「已读哪些」；没读到就禁止瞎编数字  
3. **交稿前**：旧稿对照 + 数字核对 + 交稿检查单  

原则：**旧稿与素材只在本机读；送模型只用片段，不建云端文稿库。**

## 两条不能破

1. **用户的稿不上云**（只临时送一段去 AI，不建云端文稿库）  
2. **用户看不见用的哪家模型**；你在后台切换 DeepSeek / ChatGPT…，产品只显示「标准 / 增强」

## 云后台你将来能管啥

| 管 | 不管 |
|----|------|
| 用户开关、邀请码、套餐次数 | 用户硬盘上的文件 |
| **换模型**（增强→GPT 等） | 在后台打开别人的正文 |
| 手册 / 模板 / 分类上下架 | |
| 谁在刷额度、一键踢人停用 | |

## 用户能设置啥 · 管理员能设置啥

### 用户（扩展 / 编辑器里）

| 能设 | 不能设（或以后弱化） |
|------|----------------------|
| 登录 / 退出账号 | 选 DeepSeek 还是 GPT（你后台定） |
| **仅对话 / 授权改稿** | 手填长期中转密码（改登录短票） |
| 精修、校对里勾哪些检查项 | 改别人的套餐、换全站模型 |
| 默认公文分类、常用手册（从下发列表里选） | 把正文「存到云端」 |
| 本机模板（只存在自己电脑） | |
| 隐私：是否允许把选区送去云端做 AI | |
| 导出、存版本、快照、主题等本机项 | |
| 查看自己大概还剩多少额度（只读） | |

现在已有的设置大对话框（通用 / 撰写 / 精修 / 校对）继续用；商业化后上面「登录、分类、额度」加进去。

### 管理员（云后台）

| 模块 | 能设什么 |
|------|----------|
| 用户 | 禁用、踢下线、设备数上限、邀请码 |
| 套餐 | 每月次数/token、能用「标准/增强」哪几档、超额是拒绝还是降级 |
| 给人开通 | 开通/续期订阅、赠送次数 |
| **换模型** | 「增强」走哪家模型、「标准」走哪家；一键切换、挂了切备用 |
| 内容 | 公文分类、写作手册、模板、写作步骤（剧本）上下架 |
| 安全 | 限速、单次最长字数、黑名单、看谁在猛刷、紧急停 AI |
| 系统 | 维护模式、最低软件版本、管理员账号 |

**管理员也不能：** 打开用户电脑上的稿、当网盘管文件。

## 防别人白嫖你的付费模型

- 取消「大家共用一个长期密码」  
- 必须**登录拿短票**，每次请求验票  
- **先查还有没有次数，再调用模型**  
- 不做「任意聊天进 GPT」的通用代理  

## 分几步做（别并行）

| 步 | 一句话 |
|----|--------|
| **S0** | 定案（就是本文） |
| **S1** | 登录 + 短票 + 额度门闩 + 后台换模型 |
| **S2** | 分类/手册/模板下发到本机 |
| **S3** | 写作步骤引导（剧本） |
| **S4** | 后台界面（用户/套餐/路由/内容） |
| **S5** | 试用邀请码、收费开通 |

现有撰写/精修/校对**先保留**，只把「谁能用 AI、用哪档脑子」接上云。

## 你现在只需记住

> **稿在本地 · 旧稿素材也能用（学风格、对数、防重复）· 脑在云上可换 · 用之前先验票扣额度。**

细节不用背；往下是给模型的说明书。

# §1 起 · 给模型执行（详细）

## 1. 铁律（实现约束）

### 1.1 本地权威

- 文稿 md、素材、版本、快照、本机会话/记忆：只在用户磁盘  
- 云允许：账号、套餐、用量元数据、官方手册/模板、脱敏审计（user/api/tokens/时间，**无全文**）  
- 禁止：云端「我的文稿」、后台预览用户正文、强制同步工程全文  

### 1.2 模型不可见 + 热切换

- C 端只传 `capability`：`fast` | `strong` | `proof`（UI 文案：标准/增强等）  
- 禁止正式 UI 展示/选择 DeepSeek、ChatGPT、provider 名  
- 服务端表 `model_routes`：`capability` + `task` → `provider` + `model`；改表即热切换  
- 厂商 Key 仅服务器环境变量  

---

## 2. 架构

```text
本地扩展/编辑器（文稿权威）
    │  HTTPS：短票 + 选区/上下文（临时）
    ▼
云：鉴权 → 配额 → 模型路由 → suggest/chat/proofread
    │
    ├─ SQLite 控制面（非文稿库）
    └─ 后台 Admin（用户/套餐/路由/内容/风控）
```

双运行时（VS Code 嵌入 / 本机 app.py）共用同一套云 API 契约。

---

## 3. SQLite 控制面（实体）

| 表 | 用途 |
|----|------|
| `users` | 账号 status |
| `sessions` / refresh | 可吊销登录 |
| `plans` | 套餐、capability 集合、配额数字 |
| `subscriptions` | 用户订阅与到期 |
| `usage_events` | api、capability、tokens、ms、ok |
| `categories` / `manuals` / `templates` / `playbooks` | 官方内容 |
| `model_routes` | 热切换路由 |
| `invite_codes` | 试用 |
| `admin_users` | 与 C 端分离 |
| `audit` 可与 usage 合并 | 无正文 |

**禁止** `documents` 存用户全文。

---

## 4. S1 实现要点（下一期唯一工程主题）

### 4.1 鉴权

1. 废除正式环境长期共享 `relayToken` 作为唯一门槛（调试可限 IP 过渡）  
2. 登录 → `access_token`（15–30min）+ `refresh_token`（可吊销）  
3. `POST /api/suggest|chat|proofread`：无有效 access → **401**，不调模  
4. Admin「强制下线」= 删/作废该用户 refresh  

### 4.2 配额门闩（顺序固定）

```text
验票 → 订阅有效 → 日/月配额未超 →（可选预扣）→ 调模 → 写 usage_events
```

超额 → 402/429，文案额度用尽；**禁止**超额仍调付费模。

### 4.3 防当裸代理

- 只保留业务 API；不提供通用 OpenAI messages 透传  
- 校验 body 形态与 max chars  
- 客户端头 `X-Gongwen-Client`；缺省严限流  

### 4.4 路由

- 请求 `capability`；服务端查 `model_routes` 选厂商  
- 响应与错误**不**回传真实 model id / Key（日志可内记）  

### 4.5 客户端改动面

| 现有 | 改成 |
|------|------|
| `gongwen.relayToken` 手填长期票 | 登录态短票 |
| `gongwen.defaultProvider` 用户选模 | 隐藏；用 capability/套餐 |
| bridge 打中转 | Header 带 Bearer access |

### 4.6 验收（S1）

- [x] 无票请求调不到模型（`CONTROL_REQUIRE_USER=1` 或已设 `RELAY_TOKEN` 时）  
- [x] 超额请求调不到模型（`402`）  
- [x] 后台改 `model_routes` 后下一请求走新模（`POST /api/admin/routes`）  
- [x] UI 无新暴露厂商名（顶栏改「标准/增强」；扩展剥 `provider`；设置内账号入口）  
- [x] 用量能在库中按 user 查到（`usage_events`）  

细则：`Word/specs/2026-08-11-S1-接口与DDL.md`；冒烟：`Word/deploy/relay/test_control_smoke.py`

## 5. 后台菜单（Admin MVP）

1. **用户**：列表、禁用、踢下线、设备数上限  
2. **邀请码**：生成/作废、绑套餐  
3. **套餐**：次数/token、可用 capability、超额策略  
4. **订阅**：给人开通/续期  
5. **模型路由**：capability×task→provider/model、灰度、熔断、日预算  
6. **内容**：分类、手册、模板、剧本上下架（S2 起可先只读 API）  
7. **风控**：限速、黑名单、用量 Top、告警、紧急停 AI  
8. **系统**：维护模式、最低客户端版本、管理员账号  

不管：用户本地文件树、在线打开正文。

## 6. 内容产品（S2–S3）

| 对象 | 云 | 用户 |
|------|----|------|
| 分类 | 下发 | 新建/写作时选 |
| 手册 | 下发缓存本机 | 注入 system；tool 按节拉 |
| 官方模板 | **全局只一份**，管理员改即全体跟随 | 只读选用（落到本机再写） |
| 我的模板 | **按用户隔离的云库**（短骨架、有上限） | 增删改；**不做**从官方另存（自行复制粘贴） |
| 剧本 | 下发阶段机 | 侧栏引导 |

细则见 `2026-08-11-双轨模板.md`。正文稿仍不上云。

与模型：请求带 `category_id`/`manual_version`；手册有长度上限；超长 `get_manual_section`。

### 6.1 本机语料利用（相对网页 Chat 的差异化 · 实现约束）

| 能力 | 本机输入 | 给模型什么 | 铁律 |
|------|----------|------------|------|
| 风格参照 | 用户指定 1～2 篇旧稿 md | 抽取语气/标题/套话摘要（有上限），非全文灌入 | 只读本地；摘要可进请求，不云存旧稿 |
| 防重复 | 同工程旧版/去年稿 | 对照命中段落列表 + 建议改写点 | 优先本机 diff/检索，再按需送片段 |
| 据实写数 | `素材/` + 事实表 | tool 已读列表；无依据禁造数 | 沿用工具环；UI 必须暴露「已读/未读」 |
| 习惯沉淀 | 用户采纳的改法、易错词 | 写入本机 `.gongwen/` 词库/记忆 | **不上云** |

扩展已有 `materialTools` / 工程根：S2 把「选参照稿」「旧稿对照」「已读素材条」做成主路径 UI，而不是藏在对话里偶发触发。

## 7. 试用与收费（产品层，S5）

- 试用：邀请码 + 登录；限次；稿仍本地  
- 订阅：额度 + 是否含 `strong`

- 私有化：控制面进内网；仍不强制云稿  
- 赢利点：订阅/席位/私有化/内容包——**不是云存储**
