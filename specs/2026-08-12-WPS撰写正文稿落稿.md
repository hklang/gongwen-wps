# 撰写落稿（对话卡直接写入）

## 定调

- **对话区**：说明 + 参考卡；**不**另开「正文稿」中转面板。  
- **落点**：参考卡上小按钮 **整篇 / 光标 / 选定 / 复制**（对标 Cursor Keep 式就地操作）。  
- **人机双写**：字进 WPS 正文；每个改正文点击先存版本。

## 卡片四按钮

| 按钮 | 行为 |
|------|------|
| **整篇** | 先存版本 → 按层级排版覆盖当前全文（点按钮即落，不再弹确认框） |
| **光标** | 先存版本 → 插入到光标处 |
| **选定** | 先清空选定范围再写入（不残留原文）；撰写钉住标题时扩成该级整块再覆盖 |
| **复制** | 剪贴板；不写文档、不存版本 |

## 版本铁律

- 整篇 / 光标 / 选定：必须先 `saveActiveToVersion()` 成功再写入；失败则中止。  
- **清空对话**绝不改正文。

## 与勾选的关系

- **默认不勾选「出结论 / 给多份」**：纯聊天。  
- **出结论**：一版 → 一张卡 → 点小按钮写入；勾选时自动勾上「给多份」。  
- **给多份**：多组卡并排。  
- **产出层级**：点选后自动填入一条不冲突的默认话术（多选合并；用户改过输入框则不再覆盖）。  
- 是否写入只由卡片按钮决定。

## 精修与粗雕

- **按层写**：未点名的更细标题层级不要默认展开。  
- **范围**：全文 / 当前划选 / 某个标题下——用户话里写明；局部研究先划选再出稿，用 **选定** 或 **光标**。  
- **整篇**慎用（多宜空白稿首次落骨架）。  
- 精修：充填与多方案润色；撰写负责粗雕骨架落点。

## 实现要点

- `GwProject.saveActiveToVersion` 为落稿前置  
- 禁止无版本保护的整篇 `Content.Text` 覆盖  
- 整篇 / 光标 / 选定：按 `Word/tools/政府公文排版规范.md` 落稿（`#` 宋体二号居中、`##` 黑体三号缩进2、`###` 楷体加黑、正文仿宋三号缩进2、行距固定30磅）；空行不落空段  
- **文档级无感**：页边距 / 页码仅在文档尚不符合时静默补一次；已有则跳过，无单独按钮  
- 正文里不应再出现 `#` `##`  
- UI：落点按钮在 `.ai-variant` 卡上，样式宜小不宜大
