## 一句话问题

现在发给模型的第一包把「用户要干什么 / 咱们有啥 / 出稿格式 / 取数人设 / 工程目录」揉成一团，人看不懂，模型更容易抓错焦点。

## 对标

| 产品 | 学什么 |
|------|--------|
| **Cursor Agent** | system 短且稳定；本轮 user **几乎就是用户打的那句话**；仓库有什么靠工具/目录，不靠把纪律粘进用户消息 |
| 本产品差异 | 公文落稿要 JSON + 井号（点选层级套字体）；本机素材要沙箱工具 |

不要学：把 20 条「硬性规则」和用户原话糊在同一段【用户问题】里。

---

## 现状（为什么看不懂）

同一条 user 里叠了：

1. 用户原话  
2. 【产出形态】  
3. 【可用上下文清单】  
4. 一段很长的【宿主约束】（JSON + 井号 + 待核实 + 份数 + 禁止声称已写入…）  
5. 中转再包一层【工作区】目录（最多 40 条路径）  
6. 有素材时第一包还换人设成「取数助手、本轮不写终稿」，与用户勾的「给多份」对着干  
7. 无素材时终稿第一包写「禁止调用工具」→ `fetch_context` 调不成，清单成空头支票  

system 另有一套工具纪律 / JSON 纪律，和 user 里的【宿主约束】**重复**。

## 目标第一包（人能扫完）

三层，各管一件事：

| 层 | 只放 | 不放 |
|----|------|------|
| **system** | 身份一句；工具怎么用；出稿协议（聊天 / 出结论 / 给多份 + 井号）；一句「缺则点名取，够了再出稿」 | 用户原话、全文、素材正文、取数人设 |
| **user** | **①要求 ②钉住原文（有则附）③还有啥（短清单）** | 纪律散文、【宿主约束】、素材摘录、全文 |
| **tools** | `fetch_context` / `list_files` / `search_materials` / `read_file` | — |

钉住 = 用户亲手划的工作面（对标 Cursor 里 @ 了一段）。不是宿主猜「该写哪」。无钉住则 ② 整块省略。

理想 **user** 长这样（可验收）：

```
【要求】
加入大冬会成立党支部的事

【钉住】
（二）攻坚大冬会场馆，扛牢政治任务。
……原文……

【还有什么】（未附正文；要则点名）
- 全文 doc_full：有，约 6000 字 → fetch_context(["doc_full"])
- 素材：有，约 12 个文件 → list_files / search_materials / read_file
```

理想 **system** 长这样：

```
你是机关公文助手。本轮以【要求】为准；【钉住】是用户划定的原文，用不用、怎么用由你判断。
【钉住】已附原文则不必再 fetch pin。
【还有什么】里未附的正文，缺则 fetch_context / list_files / read_file，够了再出稿。
出稿：勾了「给多份」则只输出 JSON {reply, options:[{id,md,note}]}，edit=null。禁止 markdown 代码围栏。
井号跟点选走（本轮：正文=不要标题井号）。无出处标【待核实】。
```

「问他要啥」= 清单 + 允许 tool，模型用工具就是在要。  
**不是**再立「取数助手、本轮不准写稿」——那会和勾选「给多份」对打。

## 选项

### 第一包结构

| | 做法 | 利 | 弊 |
|--|------|----|----|
| **A 推荐（已按用户本轮调整）** | 第一包 user = 要求 + 钉住原文 + 还有啥；system 允许 tool；够了直接出稿 | 工作面一眼可见；其余仍点名 | 钉住很长时包会变大（可截断并标明 truncated） |
| B | 钉住也只报「有 N 字」，等 fetch | 包更短 | 模型可能不取钉住，要求悬空 |
| C | 强制第一轮只能 tool、不能出 JSON | 像「问他要啥」 | **不做**：即取数人设，和给多份打架 |

### 工程目录（「有啥」要细到哪）

| | 做法 | 利 | 弊 |
|--|------|----|----|
| **A 推荐** | 清单只写「素材：有，N 个文件」；目录等 `list_files` | 第一包短 | 多一轮 list |
| B | 第一包附短目录（路径+标题，无摘录） | 选型快，仍是「有啥」不是正文 | 包会变长 |
| C | 继续塞摘录 snippet | — | **不做**（没要就给正文） |

### 近轮对话（按 `想构思` 对标后再裁）

归类：右侧续聊改稿，不是「再塞一个仓库文件」。  
对标：**Cursor Agent 聊天线程**（飞书智能伙伴同构：侧栏对话本身就是上下文）。

Cursor 怎么给：

| | Cursor | 咱们不该发明的 |
|--|--------|----------------|
| 通道 | 就是 `messages` 里一轮轮 user / assistant | 把聊天再做成 `fetch_context(history)` 当文件取 |
| 本轮 user | 用户刚打的那句 + 本轮 @（选区/文件） | 把纪律、清单、历史摘要糊进同一段 |
| 上一轮 user | 当时打的原话（可含当时的 @） | 把【宿主约束】写进历史让模型学舌 |
| 上一轮 assistant | 线程里留回复；**已写入文件的稿以文件为准** | 清单写「近轮对话：3 条，要则 fetch」；让模型另写「给下轮看的备忘」 |

现状（代码已落地）：`pruneHistory` 助手只留口语首句，**不带**各组 md。未点写入时下一轮说「用第二组再改」→ 模型看不见稿，正文里也没有。

**已定（仿 Cursor，只裁差异）**

```
messages:
  system: （协议，稳定）
  user: 近轮用户原话
  assistant: 口语；【同钉住才附最近一次卡片全文】
  user: 【要求】+【钉住】+【还有什么】   ← 仅本轮
```

- 对话**不进**【还有什么】  
- `fetch_context(history)` **不做主通道**  
- **不**让模型另写线索/备忘；宿主按卡片机械拼接  
- 侧栏气泡仍短句；带给模型的 assistant 可以比气泡长  

**带不带上轮卡片（08-14 拍板）**

| 情况 | 发给模型 |
|--|--|
| **没换钉**（钉子还是那一块，或这轮没钉住） | 口语 + **最近一次**各组 `id/note/md` 全文 |
| **换钉**（`work.start/end` 与出那轮卡片时不同） | 只带口语，**不带**卡片长文 |

没换钉 = 继续研究这一段。换钉 = 新工作面，跟上一轮稿无关。  
只看钉子范围，不猜 intent。更早轮只留口语。不写「B 已落稿」。点没点选定都不拆组。合计超约 8000 字才截断并标 truncated。

代价：「按第二组口气写**新**段」接不上——先说要点，或先别换钉。

Q1～Q5 不再单拍：全文硬顶截断；同轮各组都带；只最近一次出卡片的那轮；历史用户句不附旧钉住；不报已落稿。

**每轮发给模型的整包（人看这张表）**

| 块 | 现在 | 拍板 |
|--|------|------|
| system | 身份、工具、JSON、井号 | **已定** |
| 本轮【要求】 | 你刚打的那句 | **已定** |
| 本轮【钉住】 | 你当前划的原文（有则附） | **已定** |
| 本轮【还有什么】 | 全文/素材：有无+字数，正文不预塞 | **已定** |
| 近轮你说的话 | 气泡原话（不是当时那包【钉住】） | **已定** |
| 近轮模型口语 | 「已出 3 组」这类短句 | **已定** |
| 最近一次卡片 md | **同钉住才带**；换钉不带 | **已定** |
| 更早轮的卡片长文 | 不带，只留口语 | **已定** |
| 已点选定的那组 md | 不另报「已落稿」；同钉则整轮卡片仍带 | **已定** |
| 全文 / 素材正文 | 不预塞，模型点名再取 | **已定** |
| 上一轮读过的文件正文 | 不留在对话里，下轮要再 read | **已定**（不另造记忆） |
| 让模型写「线索/备忘」 | 不做 | **已定** |

卡片：没点写入照常在侧栏；点了选定/光标/整篇 → 标已落稿。侧栏气泡仍短句；带给模型的 history 可以比气泡长。  
08-13「结果稿一律不传」**作废**。

对照：本轮【钉住】是 WPS **当前**原文；未写入的卡片是侧栏 **稿**。两者可以同时在包里——一个是正文现状，一个是还没落的稿。

### 对标收束（08-14，已拍板）

发给模型的近轮对话 = 你说过的原话 + 模型说过的话。  
**同一钉住**才把最近一次卡片全文附在该轮 assistant 上；**换钉**只留口语。  
发现性：出卡后提示补半句「也可直接说『用第二组再短一点』」；**不加**「带上一轮」勾选/按钮。

### 怕用户不知道能续改（08-14，已拍板）

**A。** 不开关。出卡后提示补半句；有同钉未写入卡片时，输入框占位改成同类话。

### 换到下一段还带上轮稿吗（08-14，已拍板）

**A。** 换钉 → 不带上轮卡片（只带口语）。没换钉或这轮没钉住 → 带卡片。  
用户原话：没换钉就是继续研究；换钉了就是跟之前的没关系。
