## UI（2026-08-11 起对齐现网侧栏）

结构照抄 editor `#aiAside`：

- 顶栏 Tab：**撰写 | 精修 | 校对** + 标准/增强
- 中部 `ai-opts`：对话泡 / 精修方案卡 / 校对问题列表
- 校对专用 `ai-proof-bar`（选区|全文 + 开始校对）
- 底栏 `ai-compose`：选区条、立意/搭架/充填 或 精修快捷、输入框、仅对话|授权改稿、发送/出方案

**本轮不做登录 UI**；有短票则带上，无票由服务端 401 提示。

样式：`ui/ai-aside.css`（自 `gongwen.css` 侧栏片段抽出）。

### 打开方式（本机）

1. **点功能区「公文助手」Tab 盖正文**：宿主 `index.html` 须零高度（已处理）。  
2. **点「打开公文助手」后盖住上半 / 功能区难点**：  
   **WPS 平台回归**（12.1.0.**26895+**，含本机 **28043**）。  
   社区复现：[topic/93291](https://bbs.wps.cn/topic/93291)、[94137](https://bbs.wps.cn/topic/94137)。  
   ≤26884 侧栏正常；改 DockPosition **无效**。  
3. **本机 28043**：停靠 TaskPane 会挡顶部/卡 Tab → **不用**。  
   **独立窗**：贴主窗右侧；高度=「功能区标签下沿 → 底栏上沿」（`UsableHeight` / `ActiveWindow`），**不盖 Tab**。无 `ShowDialogEx` 时仅能保证高度，位置可能居中。

## 选区 / 同级标题

精修：**划选 → 点芯片选中**（不改正文）；需要时点「展开」看全文（**默认收起**）。  
仅保留勾选 **「扩选同级标题」**。

> **换选卡死**与目标方案见 [`2026-08-11-WPS工作选区换选方案.md`](./2026-08-11-WPS工作选区换选方案.md)（确认后再改代码）。

| API | 行为 |
|-----|------|
| `selectSiblingHeadings` | 父级下全部同级标题行（不含下级）；**不改正文格式** |
| `highlightRange` | 仅 SetRange，不涂色 |

勾选「扩选同级标题」后点选中（或勾选瞬间）：同级标题并入工作选区。
