## 0. 定调

**宿主不做「该不该给哪段正文」的语义判断。**  
首包给：**本轮用户要求 + 可用上下文清单**；另：**用户已钉住 → 首包必附 pin 原文**（钉住=显式工作面，不是宿主猜）。  
底稿 / 全文 / 任务卡 / 历史 / 素材：模型点名要，宿主再给。

典型用法：钉住标题「（四）…」且其下尚无正文 → 首包已见标题，在其下充填；缺事实再读素材。

---

## 1. 首包必给

| 块 | 内容 |
|----|------|
| 用户本轮原文 | 不裁 |
| 产出形态 / 宿主 JSON 约束 | 出结论/多份等格式纪律 |
| Intent 焦点说明一行 | 仅推荐策略，不删内容 |
| **钉住 pin（若有）** | **原文必附**（工作面；可仅为标题） |
| **【可用上下文清单】** | 其余项有/无 + 字数；底稿/全文等不预塞 |

清单项（普惠，无专名）：

- `pin` 钉住范围（有则首包已附）  
- `base_draft` 用户已采用的结论底稿  
- `task_card` 任务卡  
- `history` 近轮对话（条数）  
- `doc_full` **当前完整正文**（字数）  
- 素材：走已有 `list_files` / `search_materials` / `read_file`

---

## 2. 点名工具

| 工具 | 作用 |
|------|------|
| `fetch_context` | `keys`: `pin` \| `base_draft` \| `task_card` \| `history` \| `doc_full`（可多项；pin 通常已附） |
| `list_files` / `search_materials` / `read_file` | 素材（已有） |

模型要 `doc_full` → 给当前完整正文。宿主不改写成摘要顶替。  
仅存在传输硬顶（API 体积）时原样截断并标明 `truncated`+总字数——**不是内容裁判**。

---

## 3. 禁止

- 按专名/关键词决定给不给  
- 首包预塞 **底稿 / 全文**（用户 @引用除外）；**钉住除外，必附**  
- 出多份自动 `baseDraft`（仍仅选定/光标/整篇）
