## 1. 对标（想构思）

| 步骤 | 结论 |
|------|------|
| 归类 | 公文骨架货架：云端发短 md，本机选用落地；正文/素材不上网盘 |
| 对标 | **本产品原编辑器 / VS Code 扩展**的模板区「☁ 云端」模态 + WPS「系统模板 + 我的模板」心智 |
| 学什么 | 官方只读母版；我的跟账号 CRUD；选用 → 写进工程 `模板/`；不做官方另存为我的 |
| 裁剪 | 壳挂在现有左侧工程栏 `☁ 云端`（已 stub）；模态可用独立窗或面板内层，**行为对齐原 tplModal**，不自创第三轨 |

商业边界（沿用双轨规格，不重开讨论）：

- 云端只存短骨架（我的 ≤50 篇、单篇 ≤32KB）  
- 本机 `模板/` = **落地缓存**，权威「我的」在云  
- 不做：官方→我的另存、用户回写官方、云端「我的文稿」库

## 2. 原实现拆解（「云端模板」到底是什么）

### 2.1 双轨与存储

```
管理员 ──upsert──► SQLite templates（官方全局）
用户登录 ──CRUD──► SQLite user_templates（按 user_id）
用户选用 ──land──► 本机工程根/模板/{文种}-{标题}.md
写作请求 ──category_code──► 中转注入 manuals（手册≠模板正文）
```

| 轨 | 权威位置 | 用户能力 |
|----|----------|----------|
| **官方** | 云 `templates` 表 | 浏览 / 预览 / 选用落地；不可改正文 |
| **我的** | 云 `user_templates` | 列表 / 新建 / 编辑 / 删除；跟账号跨设备 |
| 本机 `模板/` | 缓存 | 侧栏列表、工具环 `read_file`、引用；**不是「我的」权威源** |

### 2.2 中转 API（已实现，加载项复用）

| 路径 | 方法 | 鉴权 | 作用 |
|------|------|------|------|
| `GET /api/genres` | 公开 | 文种名录 |
| `GET /api/templates?category=` | 公开 | 某文种官方模板目录（无全文） |
| `GET /api/template?code=` | 用户/开放 | 官方模板正文 `body_md` |
| `GET /api/skeleton?category=` | 同上 | 无专用码时按文种骨架 |
| `GET /api/user/templates` | **登录短票** | 我的列表；`?id=` 取全文 |
| `POST /api/user/templates` | 登录 | `op=create\|update\|delete` |
| `GET /api/content/pack` | 用户 | 官方整包（手册+模板+剧本）— **本期可选后置** |
| `POST /api/admin/template` | 运维票 | 改官方 — **加载项不做** |

关键 JSON（摘要）：

- 官方列表项：`code, title, category, blurb, …`  
- 官方正文：`body_md, title, category, …`  
- 我的列表：`id, title, category_code, updated_at, chars`（无全文）  
- 我的全文：`id, title, category_code, body_md, updated_at`  

实现锚点：`control_content.py`、`control_user_tpl.py`、`relay_server.py`。

### 2.3 原 UI 流程（必须对齐）

入口：侧栏模板区 **☁ 云端** → `openTplModal()`。

| 轨 | 行为 | 函数/API |
|----|------|----------|
| 官方 | 选文种 → 列模板 → 预览 `body_md` → **选用落地** | `loadTplList` / `previewTpl` / `landCloudTemplate` |
| 我的 | 列表 → 打开编辑 → 保存/删除/新建 | `loadMineTplList` / `saveMineTpl` / `deleteMineTpl` |

**落地语义（原站一比一）**：  
`land` → 写入工程 `模板/`（非静默替换当前 docx 全文）。落地后用户在侧栏打开/引用；对话靠 `@` / 工具读文件，**不自动把模板正文塞进写作请求**。

### 2.4 与写作的关系（勿混淆）

| 能力 | 是否模板轨 | 说明 |
|------|------------|------|
| 模板浏览 / 我的 CRUD / land | ✅ 本期 | 云骨架 ↔ 本机 `模板/` |
| `_official_inject`（手册） | ❌ 另题 | suggest/chat 按 `category_code` 注 manuals |
| 文种面板选 `categoryCode` | ❌ 另题 | 触发手册注入的前提 |
| `content/pack` 整包 sync | ❌ 可后置 | `.gongwen/official/…` |

本期 **不对齐** 文种面板与手册注入；只保证「云模板能看见、我的能改、能落到本机夹」。

## 3. 现状 vs 缺口

| 能力 | 原编辑器/中转 | 当前 WPS 加载项 | 本期 |
|------|---------------|-----------------|------|
| 双轨 API（中转） | ✅ | 同源可调 | 沿用 |
| `GwRelay` genres/templates/user | ✅（editor fetch） | ❌ 无封装 | **要做** |
| ☁ 入口 | ✅ | `projAside` 按钮仅 stub 提示 | **要做** |
| tplModal 官方/我的 | ✅ | 无 | **要做** |
| land → `模板/` | ✅ `landUserTemplate` | 有夹与列表，无写盘落地 | **要做** |
| 本机模板区列表/索引 | ✅ | ✅ `projectRoot` / `materialTools` | 沿用 |
| 文种 `category_code` + 手册注入 | ✅ | 无 | **本期不做** |
| content/pack 官方包 sync | ✅ | 无 | **本期不做** |
| 插入当前 docx 选区 | 规格曾提；原站主路径是 land | 无 | **进一步研究** |

结论：**云端与库表已一比一；缺口 = 加载项 API 客户端 + 云端模态 UI + 本机落地写文件。**

1. **接 API**：在 `relay.js`（或薄封装）增加  
   `genres` / `listTemplates` / `getTemplate` / `listUserTemplates` / `getUserTemplate` / `saveUserTemplate`（create|update|delete）

## 7. 验收

1. 未登录：官方可浏览预览；我的提示登录  
2. 已登录：我的可新建/改/删，刷新列表与云端一致；超 50 篇或超 32KB 有明确错误  
3. 「下载到本机」后，工程 `模板/` 出现文件，侧栏模板区能看到；不覆盖当前正在编辑的 docx 全文  
4. 不做官方「另存为我的」按钮  
5. 断网/中转挂：错误提示可读，不崩侧栏
