# 调研报告草稿规范

> 以后写调研报告 md 草稿都按本规范，md → docx 直接出成品，避免反复调整格式。

## 一、文档结构

```
# 大冬会场馆建设调研报告              ← 大标题
（冒段：调研背景与目的）               ← 正文
## 一、基本情况                        ← 一级标题
## 二、作法经验                        ← 一级标题
### （一）小标题                       ← 二级标题，楷体加黑
### （二）小标题
## 三、启示借鉴                        ← 一级标题
**一是xxx。**正文内容...               ← 段内混排：前缀加黑
**二是xxx。**正文内容...
## 四、下步工作安排                    ← 一级标题
**（一）xxx。**正文内容...             ← 段内混排：前缀加黑
**（二）xxx。**正文内容...
*（待补充说明）*                       ← 注释
```

## 二、标题层级规则

| 层级 | md 写法 | 字体 | 字号 | 加粗 | 缩进 |
|------|---------|------|------|------|------|
| 大标题 | `# xxx` | 宋体 | 二号(22pt) | 加黑 | 0 |
| 一级标题 | `## 一、xxx` | 黑体 | 三号(16pt) | 不加黑 | 2字符 |
| 二级标题 | `### （一）xxx` | 楷体 | 三号(16pt) | 加黑 | 2字符 |
| 段内混排 | `**一是xxx。**正文` | 仿宋 | 三号(16pt) | 前缀加黑 | 2字符 |
| 整段加黑 | `**xxx**` | 仿宋 | 三号(16pt) | 整段加黑 | 2字符 |
| 正文 | 直接写 | 仿宋 | 三号(16pt) | 不加黑 | 2字符 |
| 注释 | `*（xxx）*` | 仿宋 | 三号(16pt) | 不加黑 | 0 |

## 三、编写规则

### 3.1 二级标题必须用 `###`
- 正确：`### （一）坚持省市统筹`
- 错误：`**（一）坚持省市统筹**` → 被当成整段加黑，输出仿宋而非楷体

### 3.2 段内混排规则
- `**前缀。**正文` → 句号前加黑，句号后正常
- `**前缀：**正文` → 冒号前加黑，冒号后正常
- 句号/冒号必须在 `**` 里面

### 3.3 每层编号要有明显区分
- 第一层用 `一、二、三、` → `## 一、xxx`
- 第二层用 `（一）（二）（三）` → `### （一）xxx`
- 第四层用 `一是、二是、三是` → `**一是xxx。**正文`

### 3.4 已完成的不写
- 已完工、已稳定的事项不再写入下步安排
- 仅写当前仍需推进的工作

### 3.5 禁止分页符
- `---` 在脚本中被跳过，不起任何作用
- 不要用 `---` 分隔内容

## 四、冒段写法

```
为xxx目的，xxx时间由xxx单位组成的调研组，赴xxx学习考察，就xxx深入交流。现将有关情况报告如下：
```

- 一句话交代目的、时间、人员、地点、内容
- 末尾固定"现将有关情况报告如下："

## 五、各章节写法要点

**一、基本情况：** 客观对比两地数据（筹备天数、投资额、场馆数量等），先写调研对象，后写我市。

**二、作法经验：** 小标题格式 `### （一）坚持xxx`，每段5-6行，动词开头，数字具体。

**三、启示借鉴：** 用 `**一是xxx。**据哈尔滨经验...` 格式，先写对方做法，再写"建议我市..."。

**四、下步工作安排：** 用 `**（一）xxx。**内容...` 格式，4条左右，标题宏观不重复启示。

## 六、写作原则与工作习惯

- **无"三"不成文**：每章列举要点不少于3条，典型案例不少于3个，论点不少于3个支撑
- 修改 md 草稿后不要每次自动生成 docx，用户要求生成时再生成
- 生成 docx 前先关掉 Word（否则文件被占用报 PermissionError）

## 七、禁忌清单

- 禁止 `---` 分页符
- 禁止二级标题用 `**（一）**`（会被当成整段加黑）
- 禁止编号项用 `####`
- 禁止 `**` 中不加句号/冒号的段内混排（会匹配到整段加黑规则）
- 禁止已完成的写入下步安排
- 禁止 src2 有的进展在启示中再提（方案稳定、产权办结等）
