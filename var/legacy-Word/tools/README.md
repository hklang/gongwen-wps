# 公文排版工具

Markdown 按规范写好，一行命令出 docx，排版零手动。

## 依赖

```
pip install python-docx
```

## md 写作速查

| md 写法 | Word 效果 |
|---------|----------|
| `# 标题` | 宋体 二号 加黑 居中 |
| `## 一、xxx` | 黑体 三号 首行缩进2字符 |
| `### （一）xxx` | 楷体 三号 加黑 首行缩进2字符 |
| `#### 小标题` | 仿宋 三号 加黑 首行缩进2字符 |
| `**一是xxx。**正文` | 前缀加黑，正文正常（段内混排） |
| `**根据工作分工，**分管…` | 同上：任意标点均可，`**` 内加黑 |
| `普通**局部**继续` | 局部加黑 |
| `**整段加黑**` | 整段仿宋 加黑 |
| `<u>下划线</u>` | 下划线 |
| `<span style="color:red">红字</span>` | 字体红色 |
| `<span style="background:#000;color:#fff">黑底</span>` | 黑底白字 |
| `*（注释）*` | 仿宋 无缩进 |
| `<div align="right">xxx</div>` | 右对齐（署名/日期） |
| GFM 表格（见下方说明） | Table Grid 居中，表头加粗灰底 |

> `docx2md`：优先按字体识别；若源稿未设黑体/楷体字号，则按文案「一、」「（一）」自动补 `##` / `###`。

> 加黑落盘为 `**…**`。编辑器载入时若 CommonMark 未解析中文旁加黑，会在 DOM 中补显示；保存仍写回 `**`，不会落成 `<strong>`。

> 下划线 / 红字 / 黑底：用 HTML 行内标签（编辑器工具栏可一键插入），与 Word 双向互通。

## 命令

```powershell
# md → docx
python tools\md2docx.py 输入.md [输出.docx]

# docx → md（保留格式层级，可回排）
python tools\docx2md.py 输入.docx [输出.md]
```

不指定输出文件时，自动生成同目录同名文件。

## 注意事项

- **Python 路径**：部分机器需用完整路径 `C:\ProgramData\anaconda3\python.exe`（避免 Windows 商店劫持 `python` 命令）
- **关掉 Word**：生成 docx 前关闭 Word，否则文件被占用报 PermissionError
- **禁止 `---`**：脚本中跳过，不起任何作用
- 详细排版规则见 `政府公文排版规范.md`
- 调研报告写作约定见 `调研报告草稿规范.md`
- 其他格式转 md 方法见 `文件转md方法.md`

## 表格转换说明

md 中的 GFM 表格会自动转为 Word 表格，规则如下：

```markdown
| 序号 | 场馆 | 进度(%) |
|------|------|---------|    ← 分隔行（必填，否则不识别为表格）
| 1    | 五环 | 60      |
| 2    | 速滑 | 60      |
```

| 特性 | 效果 |
|------|------|
| **样式** | Table Grid（带边框） |
| **对齐** | 表格居中 |
| **表头** | 首行加粗 + 浅灰底纹（#D9D9D9） |
| **字体** | 仿宋 12pt，居中，垂直居中 |
| **识别条件** | 第2行必须为 `|---|---|` 分隔行，否则按普通正文处理 |
| **空行** | 表格后自动插入一个空行 |

> 注意：分隔行不能省略——没有分隔行的 `|...|` 行不会被识别为表格。

## 拿到其他项目用

复制整个 `tools/` 目录到新项目即可。两个 Python 脚本自包含，无外部依赖（除 python-docx）。
