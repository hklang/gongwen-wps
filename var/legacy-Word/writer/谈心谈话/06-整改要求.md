# 第六步：整改要求

**核心问题：要求怎么提？**

## 原理

第三板块和第一板块第三点容易重复——都在讲"怎么做"。区别在于：第一板块是讲道理（"应该"），第三板块是指路径（"怎么"）。

核心策略：不站在"纠错的法官"角度写，站到"推动发展的合伙人"角度写。

## 立论转换

同样的整改内容，切入角度不同，效果完全不同：

| 纠错角度 | 发展角度 |
|---------|---------|
| 你有问题必须改 | 改了这些，发展才能迈开步 |
| 不改就追责 | 改了就是发展的动力 |
| 旧问题没改完就是态度问题 | 旧问题没改完，发展就稳不住 |

转换方法：每条标题前半句点问题，后半句接发展后果（"问题不解决，发展就迈不开步"）。每条正文先讲"改什么对发展有什么好处"，再讲"怎么改"。

## 语气控制

同样一个意思，措辞决定感受：

| 威胁式 | 引导式 |
|-------|-------|
| 那就不是谈话能解决的了 | 这既是对学习教育负责，更是对集团的未来负责 |
| 别等着催 | 一起来推动 |
| 态度有问题 | 那就说不过去了 |
| 手伸不得 | 守住底线 |

原则：讲后果不追责，指方向不威胁，用"我们"不用"你"。

## 收尾：回到大局

整改不是终极目的，发展才是。最后一段必须把整改拉回经营大局——"最终检验整改成效的，不是材料写得多好，是任务能不能按期完成、目标能不能如期实现"。

## 角度转换的方法

第三板块最容易写成"你必须改""不改就怎样"。转换方法是：把同一件事，从"纠错语言"翻译成"发展语言"。

翻译表（不写具体词汇，写转换逻辑）：
- 纠错语言关注"谁的责任" → 发展语言关注"什么事被卡住了"
- 纠错语言关注"不改的后果" → 发展语言关注"改了能释放什么空间"
- 纠错语言用"你" → 发展语言用"我们"

实际操作：写完每条整改要求后，读一遍，圈出所有指向"追责"的词，替换为指向"推进"的词。
