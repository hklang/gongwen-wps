# 第九步：格式输出

**核心问题：怎么变成可用文件？**

## 原理

公文排版的核心价值是"零手动"——md按规范写好，一行命令出docx，格式自动对齐。

## 工具

使用 `tools/md2docx.py`。该脚本按公文排版规范自动处理：大标题宋体二号加黑居中、一级标题黑体三号首行缩进、二级标题楷体三号加黑首行缩进、正文仿宋三号首行缩进、段内混排前缀加黑、署名日期右对齐。

完整的 md 语法与 Word 效果对照表见 `tools/README.md`，详细排版参数见 `tools/政府公文排版规范.md`。

## 命令

```powershell
C:\ProgramData\anaconda3\python.exe tools\md2docx.py "输入.md" "输出.docx"
```

不指定输出文件时，自动在同目录生成同名 docx。

## 输出前检查

- 关闭 Word（文件占用会导致生成失败）
- 确认 Python 路径（部分机器需完整路径，避免系统劫持）

## 输出后验证

用 Word 打开检查：标题层级、段内加黑、署名对齐。有问题回到 md 修改，重新生成。

## 移植

复制整个 `tools/` 目录到新项目即可。两个 Python 脚本自包含，仅依赖 `python-docx`（`pip install python-docx`）。
