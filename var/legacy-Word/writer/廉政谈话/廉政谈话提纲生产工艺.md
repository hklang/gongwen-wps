# 廉政谈话提纲生产工艺

继承《机关公文通用写作规范》六阶段框架。本文仅追加廉政谈话独有的技法，通用部分不再复述。

> **0 阶段（写前必做）：** 见 [../00-搜索与积累.md](../00-搜索与积累.md)。至少看 5-10 篇同题材范文、拆解出模板和范式，再动笔。

## 适用场景

分管领导对下属的**集体廉政谈话**——领导班子成员与分管领域部门/子公司负责人之间的常规性廉政提醒。

区别于：
- **谈心谈话**——偏一对多/一对一的政治关心（参 `谈心谈话/`）
- **诫勉谈话**——针对已发现问题干部的警示纠错
- **廉政党课**——偏论述、长篇宣讲

## 上位法规支撑

廉政谈话必须有**中央级法规背书**——讲话人的口径再"接地气"，也要有"硬通货"撑场面。

**必引中央法规**（按优先级）：

| 法规 | 用途 | 引用位置 |
|------|------|---------|
| 《中国共产党廉洁自律准则》 | 总论部分定调 | 板块引语 |
| 《中国共产党党内监督条例》 | 监督责任 | 第三板块 |
| 《国有企业领导人员廉洁从业规定》 | **国企人员必引** | 全篇（5 章 38 条） |
| 《中华人民共和国监察法》 | 监督执纪 | 第三板块 |
| 《中国共产党纪律处分条例》 | 后果警示 | 第一板块 |

**引用格式**：
- 首次出现用全名+书名号：**《国有企业领导人员廉洁从业规定》**
- 后续用简称：**《规定》**
- 避免每次都读完整名

**实操**：先把中央法规转成 md 放到 `src2/`，在写作时直接查条款对应到具体子项，**比翻讲话素材找依据更快、更权威**。比如：

```
二要讲个人代价 → 翻《规定》第七条"利用职权谋取私利"10 个不准
三要讲集团影响 → 翻《规定》第三十二条"不正当经济利益应当予以没收、追缴"
```

## 素材清单

除通用规范要求的四类输入外，本类材料必须收集：

| 素材 | 来源 | 用途 |
|------|------|------|
| 集团年度工作会议主持稿 | 党委办 | 集团当年工作总基调、签订责任书 |
| 一季度/上半年经营分析会发言稿 | 总经理本人 | 当前经营节点、攻坚方向 |
| 集团廉政谈话工作方案 | 集团纪委 | 政治边界、谈话要点 |
| 集团其他领导的廉政谈话提纲 | 党委办 | 参考范式 |
| 谈话对象所在板块/部门职责 | 集团 OA | 精准对位（哪个部门盯哪种风险） |
| 涉及板块的查摆问题清单 | 党委办 | 个人谈话版必备 |

## 工序一：准备——本类独有的素材和避坑

### 必收素材

- 集团年度工作会议主持稿（找"十五五"开局、年度目标、签订责任书等表述）
- 一季度/半年经营分析会发言稿（找当前节点、攻坚方向）
- 集团廉政谈话工作方案及附件（谈话对象、谈话内容、谈话步骤）
- 集团其他领导的廉政谈话提纲（参考范式、调性）

### 本类独有的避坑规则

1. **讲话人身份决定调性**——
   - **党委书记/纪委书记**：政治化、宏观、引述中央/上级精神
   - **总经理/业务分管领导**：业务化、实操化、聚焦经营风险
   - 同一位讲话人身份要前后一致，**不能一会党委书记腔一会总经理腔**

2. **冒段的政治引述要克制**——
   - 党委书记可以引"中央纪委全会精神"
   - 总经理**只引集团层面的工作部署**（年度工作会、经营分析会、廉政工作方案）
   - 总经理腔里出现"习近平总书记"是大忌

3. **"三笔账"主题贯穿第一板块**——
   - 个人账：违纪违法的个人代价（职业、家庭、名誉）
   - 集团账：一个人出事对集团的连锁伤害（经济、经营、品牌、队伍）
   - 形势账：监管越来越严、违规成本越来越高
   - **三笔账不能调换顺序**——个人先讲最有冲击力，集团次之，形势垫底

4. **第二板块按"部门对子"切分**——
   - 不要 5 个部门各铺一段（节奏太散）
   - 要两两配对：业务相近+风险类型相关
   - 例：企业管理部+债务金融部（制度+资金）；金控+香港（投资+跨境）；智能+长润（工程+销售）

5. **第三板块"种好责任田/弹好协奏曲/筑牢防火墙"金句慎用**——
   - 党委书记腔特有，总经理腔要换成更朴素的表述
   - 替代方案：把责任压到岗位、把监督嵌入流程、把内控落到实处

## 工序二：构思——本类独有的框架

### 一级标题的设计

廉政谈话的三个要点天然构成递进：认识→对照→行动。标题转换规则：

| 用户原始措辞 | 标题转换方向 |
|------------|------------|
| "谈认识和危害" | "认清形势牢记危害，切实增强拒腐防变的思想自觉" |
| "如何结合实际工作防范风险点" | "紧扣业务实际，精准防控分管领域廉政风险隐患" |
| "压实工作责任" | "强化责任落实，推动分管领域廉政建设走深走实" |

第 3 条需要额外加工：不能直接用"压实工作责任"，要加一个正向目标（"走深走实"），让第三板块从"追责视角"变为"发展视角"。

### 第一板块子结构

用经典追问结构。廉政谈话通常使用"形势→个人→集团"三段式（注意顺序）：

- **第一条：形势**——监管越来越严，违规成本越来越高
- **第二条：个人**——赌输了赔什么（业务骨干、潜力股，全家买单）
- **第三条：集团**——一个人出事，整个条线被洗牌

或者用"个人→集团→形势"顺序（按"打到自己身上的力度"递进）。**两种顺序都成立**，但要全文统一。

### 第二板块子结构

按"部门对子"切分（参考 02-框架搭建的"子结构密度"）：

- 子条目 1：{部门 A} + {部门 B} → {风险类型 1} + {风险类型 2}
- 子条目 2：{部门 C} + {部门 D} → {风险类型 3} + {风险类型 4}
- 子条目 3：{部门 E} + {部门 F} → {风险类型 5} + {风险类型 6}

例（分管 5 个部门）：

```
一是把住决策关和资金关  →  企业管理部 + 债务金融部
二是把住投资关和跨境关  →  金控公司 + 香港公司
三是把住工程关和销售关  →  智能公司 + 长润公司
```

**子条目标题不点名部门**，只提炼核心（"决策关/资金关/投资关/跨境关/工程关/销售关"）。部门名只在内容里出现。

### 第三板块子结构

每条标题 = 前半句点问题 + 后半句扣发展。三条约 2-3 条，纵向递进（旧问题→难问题→新问题）。

3 条标准结构：
- 一把手的"第一责任"（亲自抓、负总责）
- 班子成员的"一岗双责"（管业务+管廉政）
- 监督嵌入流程+内控持续完善（接受监督+健全内控）

## 工序三：撰写——本类独有的写法

### 关键纪律：写每一块内容之前，必须先用头脑风暴研究

**先确立题目、再讨论方向、再讨论内容、再动笔**。禁止跳过讨论直接写。

## 探测性修改标记铁律

所有对提纲的试探性新增、修改，必须用 `<span>【新内容】</span>` 包裹标记：

- `<span>` 是 HTML 标签，md 渲染时不影响排版
- `【】` 中文方括号视觉上显眼，方便用户在 IDE 里快速识别
- **正确格式**：`<span>【新增/修改内容】</span>`
- **错误格式**：`<span【……】></span>`（缺 `>` 闭合，会破坏 HTML 结构）

配套流程：
- 改前先在 `var/` 备份一份带时间戳的版本
- 改中用 `<span>【……】</span>` 标记
- 改完让用户确认；用户确认后，再去掉 `<span>` 标记正式定型

### 冒段

四要素：政策依据（**总经理腔引用集团方案，不引中央**）→ 今日事由 → 目的定性 → 结构预告（"下面我谈三点意见"）。

**总经理腔的冒段范例**：

```
今天召开这次分管领域廉政谈话会，结合集团经营管理的实际，
围绕廉政这一课题和大家作个交流。当前，集团经营压力较大、
项目任务较重、融资工作较紧，越是这种时期，越要警惕廉洁风险，
越要把底线守住。今天重点围绕三个问题：算清代价看清形势，
紧扣实际防控风险，强化责任推动落实。
```

### 第一板块

三条子条目**统一用"X要看清Y"句式**：

```
一要看清监管持续收紧的趋势
二要看清心存侥幸的最终代价
三要看清岗位本身就是风险
```

每条配 130-200 字。**三动词统一用"看清"**——节奏整齐、不重复。

### 第二板块

三条子条目**统一用"X是把住Y关和Z关"句式**：

```
一是把住决策关和资金关
二是把住投资关和跨境关
三是把住工程关和销售关
```

每条配 200-300 字，**内容里点名部门**。

### 第三板块

三条子条目**统一用"一是/二是/三是"句式**：

```
一是各部室、各子公司一把手要把"第一责任"扛在肩上
二是班子成员要把"一岗双责"切实担起来
三是要把监督嵌入流程、把内控落到实处
```

每条配 200-300 字。

### 收尾

四层递进：

1. **总结定调**——廉政是底线、发展是天职，二者不是选择题
2. **当前节点**——二季度末/年中交账/关键节点
3. **具体要求**——盯紧指标、抓好落实，确保双过半
4. **收束**——走得稳靠各位、走得远靠各位

## 工序四：打磨——本类独有的注意事项

### 标题打磨三件套

- **压缩**——长标题砍到 8 字
- **统一**——三条子条目动词/句式一致（"一看清""一是把住""一是")
- **替换**——把"红线意识"等抽象话换成"程序走完、痕迹留好、规矩守住"等可操作动作

### 板块引语打磨

每节开头的板块引语要：
- **承认现状**（"取得阶段性成效"）
- **指出差距**（"但越是…越要…"）
- **引出下文**（"重点盯防三类风险"）

不写超过 80 字。

### 总经理腔关键标志

1. **第一人称"我们"**——而不是"同志们"
2. **具体动词**——盯紧/抓好/落实，而不是"贯彻落实"
3. **业务关键词**——融资/项目/改革/指标/双过半
4. **算账思维**——三笔账、四笔账
5. **零感叹号**——冷静、稳重

## 工序五：核查——本类独有的风险点

### 必查项

- [ ] 引述自查材料时，区分"对象自己写的"和"你归纳的"
- [ ] 第二板块的每条"风险点"背后必须有具体场景，不能是空话
- [ ] 业务数据（金额、比例、节点）必须能在 `src/` 原始文件中找到
- [ ] 项目名称（大冬会场馆、航空博览城、城市更新）必须能溯源
- [ ] 部门名称必须与集团实际架构一致（不能编造）
- [ ] "比如"后面的具体案例必须有出处

### 出处核查表模板

| 句子 | 涉及事实 | 出处文件 | 段落 |
|------|---------|---------|------|
| 经营指标稳步增长 | 营收数据 | 一季度经营分析会 | 第 8 段 |
| 大冬会场馆维修升级 | 项目名称 | 一季度经营分析会 | 第 20 段 |
| 国有企业布局优化与重组 | 改革任务 | 一季度经营分析会 | 第 23 段 |
| 制度怎么定、考核权重怎么分、子公司怎么管 | 职能描述 | 陈晓琳原稿 | 全文 |

## 工序六：输出

同通用规范。`md2docx.py` 一键生成，公文排版自动对齐。

**输出后必查**：
- 标题层级（## 一、## 二、## 三 各是宋体二号、楷体三号）
- 段内加粗（`**一是…**` 应在 docx 里显示为前缀加黑）
- 署名右对齐（`<div align="right">` 标签）
- 页面边距（3.17cm 左/右、2.54cm 上/下）

```

（第二板块）风险防控不能空对空，必须紧扣业务实际。
（第三板块）责任不压实，再好的制度也是一纸空文。
```

```
**一要看清监管持续收紧的趋势。**（130-200字）

**三要看清岗位本身就是风险。**（130-200字）
```

### 收尾

```
同志们，今天围绕…三个方面作了交流，归根到底一句话，**…**。

确保时间过半、任务过半。希望大家把今天的内容带回岗位、
```

## 与谈心谈话的区别

| 维度 | 廉政谈话 | 谈心谈话 |
|------|---------|---------|
| 对象 | 分管领域集体 | 一对多/一对一特定对象 |
| 性质 | 定期提醒 | 政治关心 |
| 篇幅 | 1500-2000 字 | 1000-1500 字 |
| 核心 | 业务风险 | 思想动态 |
| 第二板块 | 按部门铺风险点 | 引述个人自查 |
| 调性 | 总经理腔更常见 | 党委书记腔更常见 |
