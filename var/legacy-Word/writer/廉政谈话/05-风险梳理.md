# 第五步：风险梳理

**核心问题：分管领域有哪些具体风险点？**

## 原理

廉政谈话第二板块最容易卡壳。**核心矛盾是**：要讲到具体场景让人"对号入座"，但又不能点到具体人让人下不来台。

解决方法是：**按"部门职能 + 业务流程"反推风险类型**，再映射到"国企系统已发案例"。

## 风险梳理的三个步骤

### 步骤一：列出部门核心职能

把分管领域每个部门/子公司的**3-5 个核心职能**列出来：

例（债务金融部）：
- 融资方案设计与执行
- 债务结构优化
- 关联交易管理
- 融资审批流程管理
- 资金拨付审核

### 步骤二：每个职能找 1-2 个风险类型

例（债务金融部）：

| 职能 | 风险类型 | 案例参照 |
|------|---------|---------|
| 融资方案设计 | 违规担保、违规拆借 | 国企系统多次通报 |
| 关联交易管理 | 向关联方输送利益 | 央企巡视典型案例 |
| 资金拨付审核 | 通过虚假贸易套取资金 | 金融板块审计发现 |
| 融资审批 | 以咨询费、顾问费等名目做利益输送 | 融资领域高频问题 |

### 步骤三：按风险类型合并部门

把风险类型相近的部门**两两配对**（不要 5 个部门各铺一段，节奏太散）：

| 部门对子 | 共同风险类型 |
|---------|------------|
| 企业管理部 + 债务金融部 | 制度关 + 资金关 |
| 金控公司 + 香港公司 | 投资关 + 跨境关 |
| 智能公司 + 长润公司 | 工程关 + 销售关 |

## 风险类型速查库

按业务类型分：

### 资金类风险
- 违规担保
- 违规拆借
- 通过虚假贸易套取资金
- 以咨询费、顾问费等名目做利益输送
- 资金拨付审核不严

### 投资类风险
- 对外投资尽职调查不到位
- 不良资产清收变成利益输送
- 牌照业务合作中的利益交换
- 投资决策链条不清晰、不可追溯

### 跨境类风险
- 借"跨境"之名规避监管
- 境内外信息不对称搞利益输送
- 关联交易定价不公允
- 为不合规合作方提供便利

### 工程类风险
- 招标"量身定做"、指定品牌
- 化整为零规避公开招标
- 项目变更和签证管理不规范
- 给施工方"加塞"利益空间

### 销售类风险
- 销售"关系户"
- 回款中的"飞单"
- 物业和中介选聘中的利益输送
- 房源销售中的"茶水费"

### 制度类风险
- 制度空转（挂在墙上、念在会上、就是不落实）
- 关键岗位长期不轮岗
- 对"一把手"监督虚化
- 同级监督缺位、下级监督失灵
- 牛栏关猫（制度漏洞大）

## 风险点写入提纲的格式

```
**一是把住决策关和资金关。** {部门 A} 承担{职能 1}、{职能 2}等职能，
**{关键问题}**。这些环节如果存在瑕疵，下游执行就容易出问题。
{部门 A} 重点要盯紧{风险点 1}、{风险点 2}。{部门 B} 是{关键定位}，
{规模/特点}，**{最关键要求}**。具体要警惕{具体风险}等问题。
```

例（决策关和资金关）：

```
**一是把住决策关和资金关。** 企业管理部承担制度建设、考核分配、
子公司管控等职能，**制度怎么定、考核权重怎么分、子公司怎么管**。
这些环节如果存在瑕疵，下游执行就容易出问题。要紧盯子公司管控、
业态调整、考核权重分配等关键环节，把廉政要求嵌入业务流程、审批节点
和考核指标，杜绝"制度空转"。债务金融部是集团资金运作的总关口，
融资规模大、合作机构多、利率敏感度高，**每一笔融资、每一笔资金
拨付，都要经得起倒查**。具体要警惕违规担保、违规拆借、以咨询费
顾问费等名目做利益输送等问题。
```

## 收尾的"对一对"建议

第二板块最后加一句引导性收束，让听者回去自查：

> 以上这些风险点都是基于实际情况梳理出来的，希望大家提高警惕、警钟长鸣，把今天点到的这些环节同工作实际对一对，把该堵的漏洞堵上，该补的短板补上。

**不写超过 80 字**。
