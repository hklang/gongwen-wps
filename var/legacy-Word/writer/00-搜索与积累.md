# 第〇步：搜索与积累

**核心问题：这稿子该怎么写？业界有什么成熟范本？**

## 原理

写作质量的下限由**见过的范本数量**决定。见过 10 篇同题材的真实讲话，再下笔时脑子里会自动浮现节奏和套路。**没积累就动笔，百分之八十会跑偏**。

这一步放在六阶段之前，是写作的"预热"——积累到位，后面的准备、构思、撰写才能少走弯路。

## 三类必须搜索

### 1. 同一讲话人的历史稿

最有价值。如果讲话人之前讲过同类话题，**重点学其语感、节奏、习惯用语**（"语言指纹"）。

搜索路径：
- `src/` 同讲话人历史文稿
- 集团 OA 知识库
- 上级单位公众号（"国资小新""学习强国"等）

### 2. 同场景的成熟范文

| 场景 | 搜索关键词 |

| 分管领导集体廉政谈话 | "分管领域 廉政谈话 提纲"、"廉政集体谈话 讲话稿" |

### 3. 跨场景的通用金句库

跨场景可复用的金句（公文中高频出现的"硬话"），不限于廉政话题：

- 习近平讲话金句（"功成不必在我""我将无我"等）
- 本系统、本行业近年高频表述
- 上级文件反复出现的"四字格"对仗

## 搜索工具

### Playwright + 本机浏览器（推荐）

本项目的 `tools/` 已用 playwright 跑通百度搜索：

```powershell
# 安装（首次）
C:\ProgramData\anaconda3\python.exe -m pip install playwright

# 跑搜索（搜出来的内容自动写到 search_results/）
C:\ProgramData\anaconda3\python.exe search_demo.py "廉政谈话 提纲 党委书记"
```

search_demo.py 脚本默认抓前 5 条正文，存成 JSON 方便 Read 工具读取。

### 搜索引擎选择

| 引擎 | 适用 |
|------|------|
| 百度 | 中文公文中标率最高，CAPTCHA 较多（10 篇里 2-3 篇会被拦） |
| 必应 | 国际版可用，但中文结果质量一般 |
| 微信搜一搜 | 央企/机关公众号原文质量最高，需登录 |

**遇到 CAPTCHA**：换关键词绕开被拦的那条，或者用 Playwright 的 `search_demo.py` 多跑几个不同关键词。

## 拿到范本后怎么用

不是"找几篇抄一下"——是"找几篇**逆向工程**"。

每拿到一篇范文，按下面这张表拆解：

| 拆解项 | 怎么记 |
|--------|--------|
| 一级标题 | 范式（A 动宾 / B X人 / C 身体部位 / D 在X上下功夫 / E 必须） |
| 子条目范式 | "一要/一是/一是算清" 等 |
| 板块引语 | 80 字以内的引子，记录其结构（承认现状→指出差距→引出下文） |
| 金句 | 把所有加粗句、4 字对仗、6 字对仗、动宾排比记录下来 |
| 收尾 | 收尾公式（动词收束+集团大局升华） |
| 调性 | 党委书记腔 / 总经理腔 / 混合调 |
| 篇幅 | 字数、板块数、子条目数 |

**拆 5-10 篇后，写作模板就自然浮现**。

## 写前 vs 写后

- **写前搜索**——找方向、学套路、攒金句（10 篇以上）
- **写中搜索**——遇到具体问题（某类风险怎么表述、某类金句怎么用）时按需补搜
- **写后搜索**——对照范文检查调性、节奏、用语是否到位
