# S4 后台 Admin MVP

> 2026-08-11 · 对照商业化总方案 §5  
> **不管**用户本地磁盘与正文。

## 范围（本期）

用现有运维 API，做一个**单页后台**挂在中转上：

| Tab | 能力 | API |
|-----|------|-----|
| 概览 | health / maintenance | `GET /api/health` |
| 用户 | 列表、禁用/启用、踢下线、开通套餐 | `/api/admin/users` · `user-status` · `kick` · `grant` |
| 路由 | 列出/改 capability×task→provider/model | `/api/admin/routes` |
| 内容 | 目录；手册/模板/剧本 upsert | `/api/content/index` · `/api/admin/manual|template|playbook` |

**不做（留后）**：邀请码 UI、用量 Top、黑名单、Admin 账号体系（仍用 `RELAY_TOKEN`）。

## 形态

- 文件：`Word/deploy/relay/admin.html`
- 入口：`GET /admin`（或 `/gongwen-relay/admin` 经反代）
- 鉴权：页面公开；调用 API 带运维令牌（`Authorization: Bearer` + `X-Relay-Token`），存 `sessionStorage`，不落库

## 验收

1. 浏览器打开 `/admin`，粘贴令牌后能拉用户列表  
2. 改路由后 `GET /api/admin/routes` 可见  
3. 手册 upsert 后 index 有更新  
4. 无令牌调 API → 401/403
