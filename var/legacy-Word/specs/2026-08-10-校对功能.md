## 模式

侧栏三 Tab：**撰写**（对话）| **精修**（多套方案）| **校对**

- 撰写：对话改稿  
- 精修：选区出多套 → 预览/采用  
- 校对：范围=选区|全文；引擎可勾；问题列表采纳  
- 设置：顶栏「设置」→ **大对话框**，四 Tab：**通用 | 撰写 | 精修 | 校对**  
  - 校对 Tab 内二级：**偏好 | 场景 | 词库 | 数据**（对齐 word4）

## 代码落点

- 唯一定稿：`Word/deploy/relay/proofread.py`（云中转直接 import）
- 本机：`Word/editor/server.py` 优先走中转；离线兜底从上述文件加载，不另存副本
- 工程配置：`.gongwen/config.json`（`gongwenWorkspace.js` DEFAULT_CONFIG）

## API

`POST /api/proofread`（中转，Bearer 同现网）

```json
{
  "text": "...",
  "engines": ["punctuation","typo",...],
  "sensitivity": "strict",
  "whitelist": ["专有名词"],
  "mustfix": [{"wrong":"扶苏","right":"复苏"}],
  "facts": [{"label":"营收","value":"1.2","unit":"亿","aliases":[]}],
  "provider": "deepseek",
  "model": "..."
}
```

前端将启用中的 `factGroups[].items` 展平进 `facts` 再请求。

返回：`{ ok, results:[{type,original,start,end,suggestion,reason,sources?}], summary, checkedText }`

## 交互（对标 word4）

- 出结果后左侧正文对错误片段打黄底标记
- 点右侧条目 → 左侧滚到并高亮对应标记
- 点左侧标记 → 右侧滚到并选中对应条目
- 清空/忽略/采纳后刷新标记
- **三 Tab（撰写/精修/校对）切换时：左侧全部标记清空**（校对黄标、精修涂黑、撰写焦点）；**再次点「校对」Tab 清空上一轮结果与黄标**，需重新「开始校对」

## 本地错别字纪律

- `run_typo_local`：量词/序位（栋层余榀…）与**大写单字母馆号**（心A馆）不报；**小写夹字**（绿电f布局）与「紧23扣」「紧abc扣」必报
- 规则测试：`Word/deploy/relay/test_typo_local.py`

## 当前文稿身份（必须钉死）

校对/写盘/对话都不得「猜」打开的是哪份文件。

| 层 | 权威 |
|----|------|
| 宿主 | `activeFsPath` / `activeText`（soft shell 的 `shellPath`+`shellMd`） |
| 页面 | `activeDoc{path,filename,rel,root,hash}`，顶栏标题展示文件名 |
| 全文校对 | 先 `postSave`；宿主 `enrichProofreadBody` 在 `scope=full` 时**强制用宿主正文** |
| 结果过滤 | 服务端 `original ⊆ text`；客户端再丢弃非 `checkedText` 子串 |
| 保存/Keep | 带 `expectedPath`；与宿主不一致 → 409 |
| 切稿 | 清校对结果列表，避免上份稿的条还挂着 |

假阳性「顾刚市长…」曾出现在未打开的 `src2` 新能源稿——根因是串稿或旧结果未清，不是涛总稿正文。

## 设置分类

### 通用

- 定时保存 / 定时存版本

### 撰写

- 默认是否授权改稿

### 精修

- 默认套数、预览 diff/新稿、必须选区

### 校对

1. **偏好** — 灵敏度三卡片（默认 strict）；默认范围选区/全文  
2. **场景** — 场景药丸 + 本场景引擎 Switch（ID 与现网同步）  
3. **词库** — 白名单徽章增删；易错词列表；结果条「+白名单 / +易错词」  
4. **数据** — 事实组（启用/改名/条目 CRUD）；兼容旧扁 `facts[]`
