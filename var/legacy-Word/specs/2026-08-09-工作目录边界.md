# 工作目录边界（落地）

> 宏观对标见 `想构思.md`。本文件记硬规则。

## 规则

**打开或创建哪个 md，该文件对应的根目录就是工作目录；不牵扯其它位置。**

| 项 | 行为 |
|----|------|
| 定根 | `dirname(md)`；若在 `素材/`、`版本/`、`work/`、`快照/` 内 → 上抬到父目录 |
| 不定根 | 不再向上找父级 `.gongwen`；不用 VS Code 工作区根兜底 |
| 列表 / AI 素材 | 仅 `文稿根一层` + `素材/` + `版本/` |
| 禁止卷入 | `src2/`、`终稿/`、旁侧其它工程目录 |
| 打开 docx | 转成**同目录**同名 `.md`，不写到 `work/` |

因此：打开 `src2/xxx.md` 时，工作区是 `src2/`，不会把上层工程的其它稿卷进来。
