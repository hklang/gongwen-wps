# 选区涂黑 × 复制粘贴（理顺方案）

> 2026-08-10 · 解决「涂黑」与「蓝选 / 剪贴板」互相踩踏  
> 落点：`Word/editor/editor.html`（手势、钉子、剪贴板）；宿主转发见 `gongwenEditor.js` / `vscode-bridge.js`

---

## 1. 两个概念，不要混

| 名称 | 是什么 | 用户看到 | 用途 |
|------|--------|----------|------|
| **涂黑（钉子）** | 产品态：本轮「选定/焦点」 | 灰蓝底（`.ai-work-mark` / `.ai-focus-mark`） | 精修出方案、撰写带焦点；**失焦后仍应在** |
| **蓝选（浏览器选区）** | 系统态：`window.getSelection()` | 系统蓝色高亮 | 临时划选、剪切要删的范围；**可随时消失** |

铁律：

1. **涂黑 ≠ 蓝选**。有涂黑时，蓝选应收成折叠光标（或没有蓝选），不能整段拉蓝。  
2. **点右侧输入框 / 失焦** → 只丢蓝选，**不丢涂黑**。  
3. **点正文空白**（精修）→ 取消涂黑；点涂黑块本身 → 保留。  
4. **复制不依赖蓝选**：剪贴板优先活蓝选，否则用涂黑记下的原文。

## 2. 选区怎么操作

### 2.1 精修 Tab

| 操作 | 结果 |
|------|------|
| 同一段内拖选松手 | 落 `ai.work`（slice）+ 行内钉子涂黑；蓝选折叠进钉子 |
| 点 `##`/`###` / 加黑「一是」等 | 同级扩选，多节点涂黑；不拖跨段 |
| 拖选含 ≥2 个换行 | 拒绝，选取条提示跨段 |
| 点正文空白（非涂黑） | 取消选定、清涂黑 |
| 点右侧输入/按钮 | **保留涂黑** |

出方案只认 `ai.work`（涂黑），不认瞬时蓝选。

### 2.2 撰写 Tab

| 操作 | 结果 |
|------|------|
| 拖选松手 | 句级焦点涂黑（`data-ai-focus`）；不进精修 `ai.work` |
| 跨块/整块标题 | 只给块加 class，禁止 span 包块（防空行） |
| 点空白 | 清焦点涂黑 |
| 点输入框 | 快照焦点后 **保留涂黑**；发送带 `context_md` + 当前稿 |

### 2.3 校对 Tab

选区/全文是校对范围，与精修钉子无关；默认全文。

## 3. 复制粘贴怎么操作

宿主（VS Code）常截走 Webview 的 Ctrl+C/X/V，由 `gongwen.clipboard.*` 转发进页。

| 快捷键 | 行为 |
|--------|------|
| **Ctrl+C** | ① 有蓝选 → 拷蓝选；② 否则拷涂黑原文（`work.plain` / 焦点 md / 钉子 text）→ 写系统剪贴板。**不拉长蓝选，涂黑保留** |
| **Ctrl+X** | 未锁定时：短暂恢复可删范围 → 剪切 → 删除 DOM → **清涂黑**。锁定时只提示 |
| **Ctrl+V** | 未锁定时：光标落在涂黑起点（折叠）→ 插入；**不清涂黑**（除非插入逻辑本身改了 DOM）。锁定时只提示 |
| 右键复制 | 同 Ctrl+C 兜底（无蓝选时用涂黑原文） |

### 3.1 何时锁定（禁剪切/粘贴，复制仍可）

- AI `busy`（发送/出方案未返回）  
- 撰写 Keep/Undo 预览中（`chatPending`）  
- 精修方案预览中（`previewId`）— 精修平时人机可改，**仅 busy 锁手改**；若与现网 `aiShouldLock` 不一致，以本表「精修只 busy」为准并改代码对齐  

（撰写授权改稿：**不锁手改**，只控制 AI 能否提 edit。）

## 4. 目标状态机（精修选定）

```text
无选定 ──拖选/点标题──► 已涂黑（无蓝选或仅折叠光标）
   ▲                         │
   │ 点空白                  │ Ctrl+C（涂黑保留）
   │                         │ Ctrl+V（涂黑保留，落点折叠处）
   └────── Ctrl+X / 清选定 ◄─┘
```

---

## 5. 实现约束（理顺时遵守）

1. `rememberWorkRangeOn` / 焦点涂黑后：只 `savedRange` + **折叠**活选区，禁止 `selectNodeContents` 后保持蓝选。  
2. `clipboardPlainFromEditor()`：统一取拷贝正文；复制路径**不要**为拷贝去展开蓝选。  
3. 剪切才 `restoreClipboardSelection()`；结束后 `clearWorkAfterCut`。  
4. 粘贴前折叠到涂黑起点，结束后 `collapseAfterClipboard()`。  
5. `paintHoldUntil`：钉选后短时忽略「点空白误清」。  
6. 侧栏 `mousedown`：输入框只 `snapshotChatFocusIfLive`，**禁止** `clearAiSelection`。
