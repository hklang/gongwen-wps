# 文种面板 · 本机模板夹 · 云端骨架

> 2026-08-11 · v161

## 产品句

顶栏选文种（规范云端注入）。左侧「模板 · ☁ 云端」多套预览后下载到本机 `模板/`。提问靠用户 `@` 引用，不代选注入模板正文。

## 侧栏

`文稿 → 素材 → 参照 → 模板 → 版本`；悬停/右键：**引用**、**删除**。

## API

- `GET /api/genres` · `GET /api/templates?category=` · `GET /api/template?code=`
- `POST /api/templates/land` · `POST /api/delete-md`
