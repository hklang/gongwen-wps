# S3 剧本引导（侧栏阶段条）

> 2026-08-11 · 对照商业化总方案 S3  
> 对标：WPS / 飞书分步写作助手。可跳步；进度只存本机。

## 目标

侧栏展示「立意 → 搭架 → 充填 → 精修 → 校对」阶段条；当前阶段 `prompt` 注入对话/精修上下文。  
**不做**：强制线性、云端进度、Admin 网页编剧本。

## 云

| 项 | 说明 |
|----|------|
| 表 `playbooks` | `code, category_id, title, version, stages_json, published, updated_at` |
| `stages_json` | `[{id,title,hint,prompt,tab}]`，`tab` ∈ `write\|suite\|proof` |
| 下发 | `GET /api/content/pack` / `index` 含 `playbooks` |
| 运维 | `POST /api/admin/playbook`（legacy） |
| 种子 | `summary-flow` 挂分类 `summary` |

## 本机

- `.gongwen/official/playbooks/<code>.json` + `index.json.playbooks`
- `.gongwen/config.json` → `write.playbookCode` / `write.playbookStageId`
- 未同步时编辑器可用内置默认五阶段（不依赖云）

## 扩展 / 编辑器

- `officialSync.writePack` / `buildWritingContext`：注入「【当前阶段】…」
- 侧栏：`#aiPlaybookBar` chips；点击写阶段、可切 Tab、落盘 config
- 三 Tab 逻辑不推倒

## 验收

1. 同步后包内有 playbook（或未同步仍见默认阶段条）  
2. 切换阶段后 config 持久化  
3. 对话/精修 `inject` 含当前阶段标题与 prompt 摘要  
4. 用户正文不上云
