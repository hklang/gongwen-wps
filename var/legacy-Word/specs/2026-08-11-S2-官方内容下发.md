# S2 官方内容下发（分类 / 手册 / 模板）

> 2026-08-11 · 对照商业化总方案 S2  
> 铁律：官方包云端只读下发；用户正文仍只在本机。

## 存储

| 云 SQLite | 本机 |
|-----------|------|
| `categories` / `manuals` / `templates` / `playbooks`(S3) | `.gongwen/official/index.json` + `manuals/*.md` + `templates/*.md` + `playbooks/*.json` |

## API

- `GET /api/content/index` — 目录（无正文）  
- `GET /api/content/pack` — 完整包（需 user 或 legacy）  
- `POST /api/admin/manual` · `/api/admin/template` — 运维上下架/改文（legacy）

## 扩展

- `公文：同步官方手册与模板`  
- `公文：用官方模板新建稿`（另存本地 md，不覆盖当前稿）  
- 设置→通用：同步 / 用模板按钮  
- 设置→撰写：选分类 / 手册 / 参照稿（写入 `.gongwen/config.json`）  
- 侧栏顶条显示当前分类·手册·参照；对话/精修自动注入手册节选与参照片段（本机，不上云）
