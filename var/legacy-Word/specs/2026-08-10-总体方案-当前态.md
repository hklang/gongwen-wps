## 4. 工程与文件权威

| 概念 | 当前定义 |
|------|----------|
| **工程根** | 打开某个 `.md` 后，按规格上抬到含 `.gongwen/` / `素材/` / `版本/` 的一层（见工作目录边界） |
| **文稿权威** | 本地该 md；自动保存 / Keep / 采纳都写本地 |
| **会话** | 挂工程：`.gongwen/chats/` |

| **配置** | `.gongwen/config.json`（校对引擎、场景等） |
| **素材** | 仅当前工程 `素材/`；可用 `@文件` |

**红线（与 extension README 一致）：**

1. 云中转只收发文本，**绝不**读写用户盘或服务器业务盘当正文仓。  
2. 对话改稿 / 建文件 / 重命名只走本机 `vscode.workspace.fs` + 沙箱。  
3. 源 docx 不覆盖；导出另存；快照可找回。

> 注意：`Word/editor/README.md` 仍描述早期「打开 docx → `work\`」模型，与现网扩展/工程根 **已漂移**。以本总纲 + `specs/2026-08-09-工作目录边界.md` + `extension/README.md` 为准；停机期应回写 editor README。

## 5. 右侧三 Tab（当前行为合同）

| Tab | 用户干什么 | AI 干什么 | 锁手改 | 左侧标记 |
|-----|------------|-----------|--------|----------|
| **撰写** | 问答；可选划选作焦点 | **仅对话**：不改稿；**授权改稿**：可叠预览 Keep/Undo | busy / 预览待确认 | 焦点淡涂 |
| **精修** | 涂选（或点标题/「一是」扩同级） | 多套方案 → 预览/采用 | **仅 busy** | 涂黑钉子 |
| **校对** | 全文（默认）或选区；勾引擎 | 问题列表；采纳/忽略/白名单 | busy | 黄标 ↔ 右侧条目 |

### 5.1 铁律摘要（细节见专题）

- **未授权绝不改左侧**（撰写仅对话：`allow_edit=false`，全链路丢 `edit`）。  
- **精修无授权 UI**；有选定即可出方案；**禁止跨段**（≥2 换行或跨根级块）。  
- **涂黑 ≠ 系统蓝选**；复制可兜涂黑原文；剪切才清涂黑。  
- **切 Tab：左侧标记一律清**（校对黄标 / 精修涂黑 / 撰写焦点）。  
- **再点「校对」Tab：清空上一轮结果与黄标**，需重新「开始校对」。  
- **校对定位**：点左黄标 → 右卡片 `.on` + 双边滚动；点右 → 左定位。  
- **全文校对**：正文优先用页面刚落盘内容；本地规则必报「紧23扣」「绿电f布局」类笔误；量词/馆号（心A馆）不报。
