# 顶栏菜单与素材转换（落地构思）

> 宏观对标见 `Word/Code/想构思.md`。本文件只记本期拍板细节。

---

## 1. 顶栏菜单（v111）

对标 WPS / 办公套件顶栏分栏，不是 VS Code。

```text
文件▾ │ 保存▾ │ 导出▾ │ 转换▾ │ 设置▾  ……  文稿名  ……  工程·状态
```

| 菜单 | 项 |
|------|----|
| **文件** | 新建 · 打开… · 保存 · 重新加载 · 关闭 |
| **保存** | 保存 · 存版本 |
| **导出** | 导出为 Word |
| **转换** | 转换素材… |
| **设置** | 定时保存（默认开）· 定时存版本（默认关） |

- 「保存」在「文件」与「保存」菜单各出现一次，进同一命令（Ctrl+S）。
- 偏好进「设置」菜单（商业软件习惯），不在顶栏散落勾选；状态记本机。
- 侧栏素材区旁仍保留「转换」快捷入口。

---

## 2. 素材转换（v110 已落地）

对标：资料夹 +「转换」，不是资源管理器。

| 点 | 方案 |
|----|------|
| 列表 | 侧栏「素材」**只列 `.md`**（不列 docx/pdf） |
| 扔文件 | 用户可把 `.docx` 丢进磁盘 `素材/`；产品不画进列表 |
| 入口 | 顶栏 **转换 → 转换素材…**；素材区旁快捷「转换」 |
| 行为 | 扫 `素材/` 一层 `.docx` / `.txt` / `.pdf` → 生成同名 `.md`；已有同名 md 默认跳过，可确认覆盖；扫描件 PDF 无字时会失败提示 |
| 随时 | 临时再丢文件 → 再点「转换」；**不**监视文件夹（避 OneDrive 半写入） |
| 源文件 | docx **保留不删** |

第一期不做：子文件夹递归、PDF/OCR、列表展示非 md。
