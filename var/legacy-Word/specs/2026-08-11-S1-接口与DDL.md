## 环境变量

| 变量 | 含义 | 默认 |
|------|------|------|
| `CONTROL_ENABLED` | 启用控制面与 `/api/auth/*` | `1` |
| `CONTROL_REQUIRE_USER` | AI 接口只接受用户短票（禁 legacy） | `0`（过渡双轨） |
| `CONTROL_DB` | SQLite 路径 | `relay/data/control.sqlite` |
| `CONTROL_SECRET` | 签发 access HMAC 密钥 | 回落 `RELAY_TOKEN` |
| `CONTROL_MAINTENANCE` | 非空则 AI 全站 503 | 空 |
| `RELAY_TOKEN` | 运维长期票（legacy / admin） | — |

## 表（无用户正文）

`users` · `refresh_tokens` · `plans` · `subscriptions` · `usage_events` · `model_routes`

种子套餐：`free`（标准+校对）、`pro`（含增强）。默认路由：`fast/*`→deepseek-flash，`strong/*`→deepseek-pro。

## API

### 公开（控制面开时）

- `POST /api/auth/register` `{email,password}`
- `POST /api/auth/login` `{email,password,device_id?}`
- `POST /api/auth/refresh` `{refresh_token}`

### 需用户 access

- `GET /api/auth/me`
- `GET /api/quota`

### AI（验票 → 配额 → 路由）

- `POST /api/suggest|chat|proofread`  
  - Header: `Authorization: Bearer <access|legacy>`  
  - Body 建议：`capability`: `fast|strong|proof`  
  - 用户态：服务端覆盖 `provider/model`，响应去掉真实 model id  
  - 超额：`402`

### 运维（legacy RELAY_TOKEN）

- `GET/POST /api/admin/routes` 热切换路由；`exclusive:true` 关闭同档其它路由  
- `GET /api/admin/users?limit=`  
- `POST /api/admin/user-status` `{email,status:active|disabled}`  
- `POST /api/admin/kick` `{email}` 吊销 refresh  
- `POST /api/admin/grant` `{email,plan,days}`
## 扩展命令

- `公文：注册账号` / `登录账号` / `退出登录` / `查看额度`  
- 设置 `gongwen.capability`：`fast`=标准 / `strong`=增强  
- 短票存 SecretStorage；过期自动 refresh；无会话时回落 `gongwen.relayToken`
