## 注册模式

环境变量 `CONTROL_REGISTER_MODE`：

| 值 | 行为 |
|----|------|
| `open`（默认） | 可不填邀请码；填了则按码开对应套餐 |
| `invite` | **必须**有效邀请码 |
| `closed` | 拒绝注册 |

## 表 `invite_codes`

`code, plan_code, max_uses, used_count, expire_at, status, note, created_at`  
`status`: `active` / `revoked`

## API

- `POST /api/auth/register` 增字段 `invite_code`
- `GET /api/health` 增 `register_mode`
- `GET /api/admin/invites` · `POST /api/admin/invites`（生成）· `POST /api/admin/invite-revoke`

## 客户端

- 扩展注册 InputBox 多一步邀请码  
- `/admin`「邀请码」Tab：生成 / 作废 / 列表  

## 验收

1. `invite` 模式无码 → 400  
2. 用尽 / 过期 / 作废 → 不能再注册  
3. 成功注册后套餐=码绑定 plan  
4. 正文不上云
